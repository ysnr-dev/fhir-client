# 患者フォルダ 設計

患者を任意の階層の分類(フォルダ)に仕分けて、あとから一覧で見直すための機能。
「受け持ち」「術後フォロー」「研究 / 大腸がん」のような、現場が自由に作る患者の束を扱う。
メニューは「患者一覧 > 患者フォルダ」(`/patient-folders`)。

## 1. データの置き場所

backend の DB に持つ(上流 FHIR には置かない)。

- 中身は「誰がどの患者をどの入れ物に入れたか」という運用上の仕分けで、診療記録ではない。
- 持ち主ごとの木・並び順・本人だけが読めるフォルダは、オーダーセット(`order_sets`)と同じ形で
  backend に持つのが素直。FHIR の `Group` / `List` は入れ子の木と持ち主ごとの読み取り制限を素直に表せない。
- 患者は上流の `Patient.id` を文字列で持つだけ(`patient_chart_pins` と同じ)。氏名などは画面が上流から引く。

### 表

| 表 | 主な列 |
|---|---|
| `patient_folders` | `parent_id`(隣接リスト)、`scope`(`facility` / `department` / `practitioner`)、`owner_id`、`owner_name`、`name`、`display_order` |
| `patient_folder_members` | `patient_folder_id`、`patient_id`、`note`(メモ、200 文字まで)、`added_by_id`、`added_by_name`、`created_at` |

- フォルダは子フォルダと患者の両方を持てる(オーダーセットのような「フォルダ / 葉」の区別は無い)。
- 木は持ち主ごとに独立する(親と子の持ち主は同じ)。同じ親の中で名前は重ならない。循環は拒否する。
- 同じ患者を別々のフォルダに入れてよい。同じフォルダには 1 回だけ(一意索引)。
- 外部キーは張らない。子フォルダが残っているフォルダは削除できない。フォルダを消すと中の患者の登録も消える。

## 2. 持ち主と権限

| 持ち主 | 読む | 書く |
|---|---|---|
| 院内共通 | 誰でも | 誰でも |
| 診療科 | 誰でも | その科を担当する人(画面で判定) |
| 自分のフォルダ | 本人だけ(backend で判定) | 本人だけ(backend で判定) |

- 職種は問わない(看護師も仕分ける)。オーダーセットのように医師に限らない。
- 本人のフォルダはログイン中、`practitioner_id` のパラメータを見ずにログイン本人のものだけを返す。
  他人のフォルダとその中の患者は読み書きとも 403。ヘッダのトークン(運用ツール)と認証なしモードは制限しない。
- 診療科の担当は backend からは引けない(上流の PractitionerRole)ので、オーダーセットと同じく画面で決める。

## 3. API(`/master` の基底に乗せる)

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/master/patient_folders?department_id=&practitioner_id=` | 院内共通 + 診療科 + 本人のフォルダをフラットに全件。`member_count` は直下の患者数 |
| POST / PATCH / DELETE | `/master/patient_folders[/:id]` | 作成・名前と親と並び順の変更・削除。持ち主は付け替えない |
| GET | `/master/patient_folder_members?patient_folder_id=&include_descendants=` | フォルダの患者(下位フォルダの分も含められる) |
| GET | `/master/patient_folder_members?patient_id=&department_id=` | その患者が入っている、見えるフォルダの登録 |
| POST | `/master/patient_folder_members` | `patient_ids` をまとめて入れる(500 人まで)。入っている患者は飛ばし、`created` / `skipped` を返す |
| PATCH | `/master/patient_folder_members/:id` | メモの変更と、別のフォルダへの移動(移し先の権限も見る) |
| DELETE | `/master/patient_folder_members/:id` | フォルダから外す |

## 4. 画面

- **患者フォルダ**(`PatientFolderPage`):左に持ち主のタブとフォルダの木(オーダーセットと同じ見た目。
  ↑↓・+フォルダ・編集・削除)、右に選んだフォルダの患者。選んだ持ち主・フォルダ・「下位フォルダを含める」は
  URL に載せ、カルテの「戻る」で同じフォルダに戻る。
  - 患者の表は患者番号・氏名(カナ・ピクトグラム)・性別・生年月日・(下位を含めるときは)フォルダ・メモ・登録日・登録者。
    行を押すと患者プロファイルのドロワー、行のメニューにメモ・移動(同じ持ち主の木の中)・削除。
  - 「患者追加」は患者検索から 1 人ずつ足す(足しても閉じない)。メモを入れておくと足した患者に付く。
  - 上流で見つからない患者(削除済み)は id を出し、外せるようにする。
- **患者ごとのフォルダ**(`PatientFolderAssignModal`):患者検索の行メニューの「フォルダ」から開く。持ち主のタブ(登録数つき)にフォルダの木をチェックボックスで並べ、付け外しをその場で保存する。

患者は `Patient?_id=a,b,...` を 100 件ずつに分けて引く(`usePatientsByIds`)。
