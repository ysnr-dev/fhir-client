# 院内がん登録(登録対象の一覧・診療記録からの初期値・CSV 出力)の設計

`docs/functional-gap-backlog.md` §4.1「提出データの生成」のうち、院内がん登録(全国がん登録の届出項目を含む)の部分。
NCD・感染症の発生届は別に扱う。

- **［事実］** = 国立がん研究センター「院内がん登録 標準登録様式 2016 年版」(`docs/report-mappings/hbcr-01.md`)・
  FHIR R4・上流・このリポジトリの実装で確認した内容
- **［設計］** = 本ドキュメントの決めごと
- **［要確認］** = 配布資料で確かめていない読み

## 1. 背景とスコープ

院内がん登録は、がん診療連携拠点病院等で全腫瘍を 1 腫瘍 1 件で登録し、都道府県(全国がん登録)へ届け出る業務。
標準登録様式のテンプレート(`HBCR_01`、105 項目)は同梱済みだが、登録すべき患者を見つける手段と、診療記録から
項目を埋める手段が無く、回答は患者の基本情報だけが入った状態から手で書く形だった。

含めるもの:

- 登録対象(がんの病名が付いた患者)と登録の状況を横断して見る一覧(データ > 院内がん登録、`/cancer-registry`)
- 一覧の行からカルテの右ペインで登録(テンプレート回答)を始める。腫瘍(病名)を紐付ける
- テンプレートの初期値変数「がん登録」の追加(腫瘍の病名・診断日・病理診断・初回治療の日付・生存状況・都道府県コードなど)と、
  同梱テンプレート `HBCR_01` への初期値式の設定
- 登録済み(確定)の回答を標準登録様式の項目番号順の CSV に出す

含めないもの(§7):

- 全国がん登録オンラインシステムの届出ファイルそのものの形式、Hos-CanR への取込形式の確認
- 予後調査(生存確認)の支援、NCD・感染症の発生届

## 2. データの持ち方

### 2.1 登録(QuestionnaireResponse)

［設計］新しいリソースは作らない。登録は施設設定「院内がん登録」のテンプレート(既定 `HBCR_01` の url)への
QuestionnaireResponse 1 件 = 1 腫瘍。

| 要素 | 値 |
|---|---|
| `questionnaire` | テンプレートの canonical(url + 版) |
| `subject` | 患者 |
| `status` | `in-progress`(登録中)/ `completed` `amended`(登録済)。`entered-in-error` `stopped` は数えない |
| 拡張 `questionnaire-response-problem` | **腫瘍の病名(Condition)**。一覧からの登録で自動で入る。テンプレートの「対象プロブレム」と同じ器 |
| item | 標準登録様式の項目(linkId `hbcr_<項目番号>`) |

- ［事実］R4 の QuestionnaireResponse は `focus` を持たない(R5 で追加)。対象の病名は既存の「対象プロブレム」の拡張で持つ。
  この拡張の選択肢はプロブレムリストの病名だけなので、一覧から渡した病名がプロブレムでない(保険病名だけ)ときは、
  その病名を選択肢に足して選んだ状態で開く(`QuestionnaireResponseCreatePanel`)。
- ［設計］都道府県への届出の状況は様式の項目 [920] 都道府県届出状況・[921] 最新届出日で持つ(別の状態は作らない)。

### 2.2 登録対象(がんの病名)

［設計］`fhir/cancerRegistryHelpers.ts` の `CANCER_REGISTRY_ICD10_PREFIXES` に当たる ICD-10 を持つ Condition。

| 範囲 | 内容 |
|---|---|
| C00〜C97 | 悪性新生物。登録は原発の腫瘍ごとなので、続発性(C77〜C79)は除く |
| D00〜D09 | 上皮内癌 |
| D32、D33、D42、D43 | 脳・脊髄・髄膜の良性・性状不詳の腫瘍 |
| D35.2〜D35.4、D44.3〜D44.5 | 下垂体・頭蓋咽頭管・松果体の良性・性状不詳の腫瘍 |
| D45、D46、D47.1、D47.3〜D47.5 | 真性赤血球増加症・骨髄異形成症候群・慢性骨髄増殖性疾患・本態性血小板血症・骨髄線維症・慢性好酸球性白血病 |

- ［要確認］範囲は全国がん登録の届出対象(悪性新生物・上皮内癌・中枢神経系の良性腫瘍・骨髄異形成症候群等)を
  ICD-10 で置いたもの。届出マニュアルの対象疾患表と突き合わせていない。
- ［事実］上流の token 検索は完全一致で前方一致が無い(`server-improvement-backlog.md` C-24)。3 桁の範囲は
  4 桁の細分類(末尾 0〜9)まで広げて 100 件ずつ `code=` に並べる(データ抽出の病名と同じ手。1 回の表示で 13 本程度)。
- ［設計］疑い(`verification-status=provisional`)・否定・誤記は除く。転帰は問わない(治癒・死亡しても登録対象)。
  看護問題は除く。
- ［設計］期間は病名の開始日(`onset-date`)で絞る。登録様式の「診断日」に最も近い日付がこれで、この画面で登録した病名は
  開始日を持つ。開始日の無い病名(他システム由来)は期間で引けないので出ない(§7)。

### 2.3 施設設定

［設計］`facility_settings.cancer_registry = { "template": "<テンプレートの url>" }`(既定は同梱テンプレートの url)。
褥瘡管理の DESIGN-R と同じ形(`QUESTIONNAIRE_URL`、版を問わない)。

## 3. 初期値変数「がん登録」(`fhir/populateContext.ts`)

［設計］テンプレートの初期値式から参照できる `%` 変数に次を足す。元データの取得(`usePopulateSources`)は、
テンプレートの式がこれらの変数を参照しているときだけ行う(他のテンプレートの記入に余計な読み込みを足さない)。

| 変数 | 内容 | 元 |
|---|---|---|
| `%cancerName` | 腫瘍の病名 | 対象の Condition の名称 |
| `%cancerIcd10` | 腫瘍の ICD-10(「C18.7」) | Condition の ICD-10 coding |
| `%cancerTopography` | 局在コードの候補(様式の形式「C187」) | ICD-10 が 4 桁で C00〜C80(C77〜C79 の続発性を除く)のときだけ。それ以外(血液腫瘍・上皮内癌・3 桁だけ)は空 |
| `%cancerDiagnosisDate` | 診断日(YYYY-MM-DD) | Condition の開始日 |
| `%cancerDiagnosisBasis` | 診断根拠のコード | 確定した病理レポートがあれば組織診(SP)で `1`、細胞診(CP)だけなら `3`、無ければ空 |
| `%pathologyDiagnosis` | 病理診断 | 最新の確定した病理レポートの「診断」(LOINC 22637-3)。診断がシノプティックレポートなら組織型・グレード・pTNM・病期の要約(様式のテキストは 128 字まで) |
| `%pathologyDate` | 病理診断日 | そのレポートの日付 |
| `%pathologyHistologicType` | 組織型 | そのレポートの診断がシノプティックレポート(`docs/report-mappings/patho-synoptic.md`)なら、その組織型の選択肢の表示名 |
| `%pathologyMorphology` | [320] 形態コード(6 桁) | 組織型の ICD-O-3 形態コード(4 桁 / 性状)+ グレードの分化度 1 桁(無ければ 9) |
| `%pathologyPT` `%pathologyPN` `%pathologyPM` `%pathologyPStage` | [610] [620] [630] [600] の 4 桁コード | 回答の pT / pN / pM / pStage の表記を様式のコード表(`HBCR_PT_CODES` など)で引く。術前治療ありなら 6620 |
| `%pathologyExtent` | [680] 進展度のコード | pTNM からの機械的な読み替え(遠隔転移 440 > 領域リンパ節転移 420 > 上皮内 400 > T4 430 > 限局 410)。術前治療ありなら 660 |
| `%surgeryDate` | 初回の手術日 | 診断日以後で最も早い手術の実施記録(ハブ Procedure)の入室日 |
| `%chemoStartDate` | 化学療法の開始日 | 診断日以後で最も早いレジメン適用の開始日(C1 Day1) |
| `%radiotherapyStartDate` | 放射線治療の開始日 | 診断日以後で最も早い照射の実施日。実施が無ければコースの開始予定日 |
| `%deathDate` | 死亡日 | `Patient.deceasedDateTime` |
| `%lastVisitDate` | 最終来院日 | 最新の受診・入院(Encounter)の開始日 |
| `%prefectureCode` | 都道府県コード(01〜47) | 患者の住所の都道府県 |
| `%cancerRegistrationNumber` | 腫瘍番号 | 同じテンプレートのこの患者の登録件数 + 1 |

- ［設計］**対象の Condition** は、記入を始めたときの対象プロブレム(一覧から渡した腫瘍)が登録対象の病名ならそれ。
  そうでなければ患者の登録対象の病名のうち開始日が最も新しいもの。無ければがん登録の変数は空。
- ［設計］日付は他の変数と同じ YYYY-MM-DD で返す。様式の 8 桁は式の側で `.replace('-','')` にする(生年月日と同じ)。
- ［設計］「診断日以後」は、再発・二次がんで前の腫瘍の治療を拾わないための絞り。診断日が無ければ最も早いもの。
- ［設計］病期・組織型は、最新の確定した病理レポートの診断がシノプティックレポート(テンプレート)のときだけ入る。
  レポートの拡張 `patho-diagnosis-response` が指す回答をテンプレートごと読み(`_include=QuestionnaireResponse:questionnaire`)、
  項目コード(`pathology-synoptic`)で値を拾う。自由文の診断からは拾わない。
- ［設計］内分泌療法・内視鏡的治療・鏡視下治療の日付は作らない(薬剤の分類・内視鏡の治療目的の構造が無い。§7)。
- ［設計］有無の項目([700] など)は、日付が入るときだけ「1 自施設で施行」にし、無いときは空のまま
  (「施行なし」を機械的に入れると、まだ行っていないだけの治療を「なし」で確定しかねない)。

同梱テンプレート `HBCR_01` に設定した初期値式は `docs/report-mappings/hbcr-01.md`「FHIR リソースからの自動取り込み」。

## 4. 一覧(データ > 院内がん登録、`/cancer-registry`)

［設計］`pages/CancerRegistryPage.tsx`。入退院文書の作成状況と同じ作り(絞り込み → 表 → 件数)。

- **絞り込み**: 診断日(病名の開始日)の期間(既定は今日までの 1 年)、状態(すべて / 未登録 / 登録中 / 登録済)、
  届出(すべて / 未届出 = [920] が `10`〜`11`・`20`〜`21`・`30`〜`31` か未記入)。
- **行** = 登録対象の病名 1 件。患者(カルテへのリンク)・性別・年齢・病名(ICD-10)・診断日・転帰・
  登録(未登録 / 登録中 / 登録済)・登録日・届出状況([920])・届出日([921])・登録者・操作(「登録」/「開く」ボタン)。
- **登録との突き合わせ**: 回答の対象プロブレムがその病名を指していればその行。対象を持たない回答(手で書いたもの)は、
  その患者の行のうち診断日が最も古い行に当てる。1 つの行に複数の回答が当たるときは確定を優先し、同じ状態なら新しい方。
- **登録を始める**: 行の「登録」でカルテを `?open=cancer-registry:<Condition id>@<テンプレートの url>` で開き、
  右ペインの「テンプレート登録」にテンプレートと対象プロブレムを選んだ状態で入る(`karteUrl.ts`、`KartePage`)。
  登録中・登録済の行の「開く」はその回答の詳細(`detail=qr:<id>`)を開く。
- **CSV**: 表示中の行のうち登録済(確定・訂正)の回答を、テンプレートの項目順に 1 行 1 腫瘍で出す。見出しは項目の質問文
  (「[900] 病院等の名称」)、値は選択肢ならコード、それ以外は入力値。BOM 付き UTF-8(`lib/csv.ts`)。
  ［要確認］全国がん登録の届出ファイルや Hos-CanR の取込形式に合わせていない(§7)。
- **取得**: 病名は §2.2 の検索(`_include=Condition:subject`、500 件 × 4 ページで欠けたら `TruncatedNotice`)。
  回答はテンプレートの全版の canonical(`questionnaire=`)と候補の患者(`subject=` 100 人ずつ)で引く(褥瘡管理と同じ手)。

## 7. 申し送り

1. **届出ファイルの形式**: 全国がん登録の電子届出票・届出ファイルの形式と Hos-CanR Lite / Plus の取込形式は
   届出マニュアルで確かめてから合わせる。いまの CSV は項目番号順の控え。
2. **登録対象の範囲**: §2.2 の ICD-10 の範囲を届出マニュアルの対象疾患と突き合わせる。小児の良性腫瘍など施設の方針で
   登録するものは範囲に無い。
3. **開始日の無い病名**は期間で引けず一覧に出ない。`onset-date:missing=true` のタブを足すか、登録日(`recorded-date`)で引く
   切替を足す。
4. **内分泌療法・内視鏡的治療・鏡視下治療の初期値**: 薬剤の分類(ホルモン療法薬)と内視鏡の治療目的(EMR / ESD)、手術の到達法
   (鏡視下)から出せるが、いずれも対応表か判定の決め事が要る。
5. **病期の初期値** — **対応済み(2026-10-25)**。病理の診断をシノプティックレポート(`docs/patho-order-design.md` §4.7)で
   書いたときは [320] [600]〜[630] [680] が入る。残り: 臓器別テンプレートは大腸癌だけ(他は固形がん共通 TNM)、
   治療前(臨床)分類 [500]〜[580] は病理には無いので別の器が要る、[640] 付加因子は未対応。
6. **予後調査**: 生存最終確認日([800])は最終来院日を入れるだけ。死亡退院・都道府県がん情報からの更新、追跡期間([860])の
   計算、登録の修正時の [940]/[941] の自動更新は無い。
7. **届出の督促**: 診断日から届出期限(翌年末)までの残りを一覧に出す・期限超過を印にする。通知にはしない。
