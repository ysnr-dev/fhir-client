# 他科依頼 依頼目的テンプレート

他科依頼オーダーの「**依頼目的**」欄に貼る汎用テンプレート。依頼目的を自由文だけで
書くと「何を聞かれているのか」が読み取れず、依頼先がカルテを最初から辿り直すことに
なる。訊かれる側が答えるために要る項目を並べてある。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `consult-purpose-01.questionnaire.json` | 他科依頼 依頼目的 | `CONSULT_PUR_01` / `http://fhir-client.local/Questionnaire/consult-purpose-01\|1.0.0` |

レイアウト(`.tlf`)・マッピング定義は無し(帳票出力は対象外)。テンプレート一覧の
インポートから取り込む。カテゴリ **「他科依頼」** を拡張に持たせてある
(このテンプレートのために新設したカテゴリ。code は環境ごとに違うので、
別環境へ入れるときは `questionnaire_categories` に作った code へ差し替える)。

## 使い方

カルテ → 他科依頼 の「依頼目的」欄で「テンプレート」を押し、`他科依頼` カテゴリから
選ぶ。記入して反映すると、回答が平文になって依頼目的欄に入る。放射線の特別指示・
病理の臨床経過と同じ作りで、

- テンプレート紐付き中は欄を直接編集できない(回答と本文が食い違うため)。
  直すときは「テンプレート編集」から
- 「解除」で紐付けだけ外れ、記載された文言は残る(回答は同じ transaction で消える)
- **記入しなかった項目は出力に現れない。** 当てはまる欄だけ埋めればよい

回答は QuestionnaireResponse として残り、オーダーのローカル拡張
`consult-purpose-questionnaire-response` から参照される
(`docs/consult-order-design.md` §2.4)。カルテのタイムラインでは、この回答は
依頼カードに描かれるので単独のテンプレートカードには出ない。

## 項目

| グループ | 項目 | 意図 |
|---|---|---|
| 経過・現症 | 経過の要点 / 現在の所見 | 依頼先はカルテを読み直せない。この依頼を判断するのに要る範囲だけを要約させる |
| 依頼したいこと | 依頼の内容(複数選択) / 具体的にお聞きしたいこと | オーダーの「依頼種別」が大枠、ここが具体的な問い。答えの形が決まる書き方を促す |
| 背景情報 | 関連する検査所見 / 関係する投薬 / アレルギー・注意点 | カルテから辿れるが、見落とすと危ないものを書き出させる(抗血栓薬・造影剤アレルギーなど) |
| 希望・患者への説明 | 診ていただきたい時期 / 患者への説明 / その他の申し送り | 「患者への説明」は依頼先が患者に会ったときの前提が変わるので必ず選ばせる |

出力例:

```
【経過・現症】
  経過の要点: 2026-08-20 頃から労作時の胸部圧迫感。8/28 の安静時心電図で V4-6 の ST 低下。
  現在の所見: 血圧 148/88、脈 78 整。心雑音なし。下腿浮腫なし。
【依頼したいこと】
  依頼の内容: 診断の評価、検査の適応・実施
  具体的にお聞きしたいこと: 虚血性心疾患として冠動脈造影の適応があるかご意見をお願いします。
【背景情報】
  関連する検査所見: 8/28 心電図 V4-6 ST低下。8/28 トロポニンI 陰性。8/20 LDL 158。
  ...
```

## 科ごとのテンプレートを足すとき

このテンプレートは科を問わない汎用版。「循環器科への術前評価依頼」のように
訊く項目が決まっているものは、別テンプレートとして同じカテゴリに足す
(依頼先の科ごとに既定テンプレートを持たせる仕組みは未実装。
`docs/consult-order-design.md` §8 の申し送りを参照)。

## JASPEHR の制約

`choice` の項目には `questionnaire-itemControl` 拡張が必須(jsp-6)。付け忘れると
上流の登録が 422 で落ちる。単一選択は選択肢が 5 つ前後なので `radio-button`、
複数選択は `check-box` にしてある。
