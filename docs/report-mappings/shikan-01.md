# 歯科疾患管理計画書（初回）マッピング定義

`shikan-01.mapping.json` は、テンプレート「歯科疾患管理計画書（初回）」
(`http://example2.com`、name: `SHIKAN_01`)の回答を、紙様式を再現した ThinReports
レイアウト(`歯科疾患管理計画書.tlf`)へ流し込むためのマッピング定義です。
管理画面 `/report-layouts` でレイアウト登録時に「マッピング定義」欄へ貼り付けて使います。

## 対応の要点

- **メタ情報**: `pt_name`→`patient_name`(「{value} 様」書式)、`qr_authored`→`date`、
  `qr_institution`→`organization_name`、`qr_author`→`practitioner_name`。
- **テキスト**: 現存歯→`17`、医薬品→`8_2_1`、治療の予定／その他→`14_4_1`、
  その他・特記事項→`remark`(備考欄)。
- **描き込み画像**: 口腔内の状況(`item-ms7awhoy-78`)の描き込み画像→`mouth_image`
  (無地の口腔図 `default_mouth_image` はレイアウト側で常時表示)。
- **チェック・丸囲み**: 検査結果(プラーク/歯肉の炎症/歯の動揺/歯周ポケット)、服薬、
  基礎疾患(現在治療中＋疾患名の丸囲み)、口腔機能低下、改善目標、治療の予定を
  code で出し分けます。

## 意図的な集約(帳票側の選択肢が粗いもの)

- プラーク・歯石: code `02 多い`・`03 少ない` はどちらも「あり」(`9_2`)に集約。
- 基礎疾患: `03 呼吸器疾患`・`05 骨粗鬆症` は疾患名の丸囲みが紙様式にないため
  「その他」(`7_2_5`)に集約。何か 1 つでも回答があれば「はい」(`7_2`)にチェック。
- 改善目標: `04 飲料物`・`05 間食` は「食生活習慣」(`15_2`)に、`01 歯磨きの習慣`・
  `02 歯ブラシ等の使用` は「歯磨きの仕方」(`15_3`)に集約
  (code `02` は器具の内訳を持たないため `15_3_1`〜`15_3_3` の個別丸囲みは駆動できない)。
- 治療の予定: `01 ブリッジ`・`02 義歯` は「義歯・ブリッジ」(`14_3`)に集約。

## マッピングしていない項目

**帳票側に入力源がない**(Questionnaire に設問がなく、常に空欄・非表示のまま):
お口のお手入れ(`1_*`, `2*`)、喫煙習慣の「なし/過去にあり」(`3_1`/`3_3`)、
睡眠時間(`4`)、食生活(`5_*`, `6_*`)、現在治療中「いいえ」(`7_1`)・肝炎(`7_2_2`)、
歯や口の状態と全身の健康(`13_*`)、治療期間(`16_*`)、口腔機能低下の内訳。

**Questionnaire 側に出力先がない**(帳票に出力されない):
歯や歯肉の状態/虫歯(`item-ms7abno8-43`)、小児口腔機能の問題(`item-ms7aj2uw-56`)、
改善目標の `06 口腔機能の改善・獲得`・`99 その他`、各「その他」自由記述
(`item-ms7a526j-30`、`item-ms7acv6n-45`、`item-ms7a1ttf-21`、`item-ms7a4udl-29`、
`item-ms7aptmo-67`)。備考欄(`remark`)に出すのは「その他・特記事項」のみ。
