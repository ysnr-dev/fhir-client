# 問診票(一般)テンプレート(Web 問診の例)

患者が自分の端末で答える Web 問診(`docs/web-intake-design.md`)の例。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `intake-general-01.questionnaire.json` | 問診票(一般) | `INTAKE_01` / `http://fhir-client.local/Questionnaire/intake-general-01\|1.0.0` |

レイアウト(`.tlf`)・マッピング定義は無し。テンプレート一覧のインポートから取り込み、
「管理 > 施設設定 > Web 問診」の質問票に並べる(診療科ごとに別の質問票を使うなら診療科の欄で選ぶ)。

## 患者向けの質問票の条件

- 最上位の項目はグループにする。**グループ 1 つが 1 ページ**になり、ページを送るたびに必須の入力を確かめる。
- 初期値の変数(`%患者名` など)・計算式・シェーマ画像・医療機関や医療従事者の選択は使わない
  (患者画面はログインが無く、`/fhir` を読めない)。`boolean` 型は無いので「はい / いいえ」の choice にする。
- 用語は患者向けに。「ある」を選んだときだけ内容を聞く形は、JASPEHR の制約どおり choice の子のグループに enableWhen を付ける(質問は親の choice)。

## 項目

| グループ | 項目 |
|---|---|
| 今日の受診について | 症状(必須)/ いつから / 症状の変化 |
| これまでの病気と薬 | 治療中・過去の病気(ある → 病名と時期)/ 飲んでいる薬(ある → 薬の名前)/ アレルギー(ある → 内容) |
| その他 | 妊娠の可能性・授乳 / 喫煙 / 医師に伝えたいこと |
