# 透析の患者メモの雛形テンプレート

透析の患者メモ(`docs/dialysis-order-design.md` §6.1)の雛形。テンプレート一覧のインポートから取り込むと、
透析オーダーの詳細とボードの「患者メモ」から書けるようになる(施設設定は無い。アプリは url で探す)。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `dialysis-memo-01.questionnaire.json` | 透析の患者メモ | `HD_MEMO_01` / `http://fhir-client.local/Questionnaire/dialysis-memo-01\|1.0.0` |

項目や台紙を施設の様式に合わせるときは、**同じ url のまま**テンプレート編集で版を上げる(url を変えると患者メモの入口から見つからない)。
カテゴリ・帳票(`.tlf`)は無い。

| グループ | 項目 |
|---|---|
| (なし) | 導入年月日(日付) |
| 穿刺 | 消毒液(クロルヘキシジンアルコール / ポビドンヨード / 消毒用エタノール / その他)・消毒液の補足 |
| 止血 | 止血方法(用手圧迫 / 止血ベルト / 止血パッド / その他。複数)・止血時間(分)・止血の補足 |
| (なし) | シャントのシェーマ(両上肢の掌側の台紙に描き込む)・注意事項 |

- バスキュラーアクセスの種類・部位と穿刺針は透析オーダーの透析条件にあるので持たない。
- 台紙は自作の線画(両上肢の掌側。患者の右が向かって左)。下肢や人工血管の図にしたいときは、テンプレート編集でシェーマの画像を差し替える。
