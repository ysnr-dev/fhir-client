# 初期計画(Initial Plan)テンプレート

POMR の 5 要素のうち **初期計画(Initial Plan)** にあたるテンプレート。プロブレムを立てた
ときに、方針を **診断計画(Dx)・治療計画(Rx)・教育計画(Ex)** の 3 つに分けて書く。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `plan-01.questionnaire.json` | 初期計画(Dx/Rx/Ex) | `PLAN_01` / `http://fhir-client.local/Questionnaire/plan-01\|1.0.0` |

レイアウト(`.tlf`)・マッピング定義は無し(帳票出力は対象外)。テンプレート一覧のインポートから
取り込む。カテゴリ **「診療計画」**(code `b41c7e28-9f56-4d03-8a17-5e2c9b04af61`)を拡張に持たせて
ある。

## 使い方: 診療記録の「治療計画(P)」に貼る

**単独登録ではなく、診療記録の P セクションに『テンプレート記載』で貼り付けて使うことを勧める。**
SOAP の P は本来この 3 分割で書くもので、記録と計画が同じカードに収まる方が経過を読みやすい
ため。記録に貼れば、記録の対象プロブレムがそのまま計画の対象になる。

単独登録でも対象プロブレムは選べる(回答自体にプロブレムを紐付けられるので、プロブレムの
絞り込みにも乗る)。診療記録に紐付かない計画だけを残したい場合はこちらを使う。

プロブレムを選んでから「診療記録」を開くと対象プロブレムが初期選択されるので、その状態で
P セクションの「テンプレート」から選ぶ。反映すると次の形で P 欄に入る。

```
【診断計画(Dx)】
鑑別診断・想定される原因: ...
確認する検査・診察: ...
確定・除外の目安: ...
【治療計画(Rx)】
治療方針: ...
...
```

## 構成

| グループ | 項目 |
|---|---|
| 診断計画(Dx) | 鑑別診断・想定される原因 / 確認する検査・診察 / 確定・除外の目安 |
| 治療計画(Rx) | 治療方針 / 薬物療法 / 非薬物療法・処置 / 治療目標 |
| 教育計画(Ex) | 患者・家族への説明内容 / 自己管理の指導 / 次回受診・受診の目安 |
| (最後) | 計画の見直し予定日 |

- 各項目の意図は `designNote`(編集画面の「設計メモ」。回答フォームには出ない)に書いてある。
- **オーダーそのものは書かない**。「確認する検査」「薬物療法」は方針としての記載で、実際の
  検査・処方は検査オーダー・処方オーダーで出す(記録とオーダーが二重にならないようにする)。
- **計画の見直し予定日**を最後に置いている。初期計画は立てたままにせず経過記録で評価するため。

## 項目コード(item.code)を入れていない理由

社会歴は JP Core の生活背景コードに 1 対 1 で対応させているが、初期計画の各項目に対応する
確度の高い標準コードは見当たらない。当てずっぽうのコードを入れる方が無コードより害が大きい
ので入れていない(同じ理由で家族歴・システムレビューにも入れていない)。したがって
「回答から Observation を生成する」も無効のまま。計画は自由記載の方針であり、構造化データと
して検索・集計する対象でもない。

## 将来の拡張

方針を FHIR の `CarePlan` / `Goal` として構造化する道もあるが、リソースの追加と一覧・編集 UI が
要る重い変更になる。まずはこのテンプレートで「3 分割して書く」運用を定着させ、必要になった
時点で検討する。
