# NCD 症例登録(基本項目)テンプレート

NCD(National Clinical Database)の症例登録の基本項目。NCD 症例登録の一覧(`docs/ncd-registration-design.md`)から
手術の実施記録を選んで記入する(回答の `partOf` が実施記録を指す)。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `ncd-case-01.questionnaire.json` | NCD 症例登録(基本項目) | `NCD_CASE_01` / `http://fhir-client.local/Questionnaire/ncd-case-01\|1.0.0` |

レイアウト(`.tlf`)・マッピング定義は無し。テンプレート一覧のインポートから取り込む。カテゴリは
**「検査」**(code `25675b10-0ef3-4425-83c4-c1f8c3015cca`)。

## 構成

| 群 | 項目 |
|---|---|
| 患者 | 氏名・性別・生年月日・手術時年齢・身長・体重 |
| 手術 | 手術日・主術式・レセ電算コード・術式(すべて)・診療科・緊急区分・予定区分(申込)・執刀医・助手・麻酔科医・麻酔方法・手術時間・麻酔時間・出血量・輸血・輸血量・創分類 |
| 術前 | ASA-PS・緊急(E)・術前のリスク因子(複数選択)・補足 |
| 術後(30 日) | 術中の合併症(実施記録)・術後合併症(NCD の区分、複数選択)・Clavien-Dindo 分類・再手術・入院日・退院日・術後在院日数・転帰・術後 30 日以内の死亡・死亡日・補足 |
| NCD 登録 | **登録状況(未登録 / 登録済)**・登録日・NCD 症例番号・登録者・その他 |

- **登録状況(`ncd_status`)と登録日(`ncd_registered-on`)の linkId は変えない**。一覧が「登録済」の判定と登録日の表示に使う
  (`fhir/ncdHelpers.ts`)。
- 術後合併症の区分は NCD の基本項目の合併症(手術部位感染 3 区分・縫合不全・出血・腸閉塞・肺炎・呼吸不全・肺塞栓・
  深部静脈血栓症・心筋梗塞・心停止・脳血管障害・腎不全・尿路感染・敗血症・創離開・せん妄・その他)。領域ごとの合併症は
  テンプレートを複製して足す。

## 初期値

| 項目 | 初期値 |
|---|---|
| 氏名・性別・生年月日・年齢・身長・体重 | 患者情報と最新の身長体重(`%age` `%bodyHeight` `%bodyWeight`) |
| 手術日・主術式・コード・術式(すべて)・執刀医・助手・麻酔科医・手術時間・麻酔時間・出血量・輸血・輸血量・創分類・術中の合併症 | 手術の実施記録(`%ncdSurgeryDate` `%ncdProcedureName` … `%ncdComplicationNote`) |
| 診療科・予定区分・麻酔方法 | 手術の申込(`%ncdDepartment` `%ncdPriority` `%ncdAnesthesia`) |
| 入院日・退院日・術後在院日数 | 手術日を含む入院(`%ncdAdmissionDate` `%ncdDischargeDate` `%ncdPostoperativeDays`) |
| 術後 30 日以内の死亡・死亡日 | 患者情報の死亡日(`%ncdDiedWithin30Days` `%ncdDeathDate`) |
| 登録状況 | 未登録 |
| 登録者 | ログイン中の医療従事者 |

変数の中身は `docs/ncd-registration-design.md` §3。

## 検証(2026-10-25、開発環境)

- NCD 症例登録の一覧の「登録」から開いた回答に、手術日・術式・コード・執刀医・麻酔・手術時間・出血量・輸血の有無・創分類・入院日が
  入ること。登録状況を「登録済」にして確定すると一覧が「登録済」になること。
