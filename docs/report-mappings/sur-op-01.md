# 手術記録テンプレート

手術後に執刀医が書く手術記録(オペレコ)のテンプレート。カルテの「テンプレート」から
記入する単独のテンプレートカード方式で、放射線・内視鏡の特別指示のようにオーダーへは
紐付けない(1 手術 1 記録で、読む人もカルテを開く人だから)。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `sur-op-01.questionnaire.json` | 手術記録 | `SUR_OP_01` / `http://fhir-client.local/Questionnaire/sur-op-01\|1.0.0` |

レイアウト(`.tlf`)・マッピング定義は無し(帳票出力は対象外。記録・保管用のテンプレート)。
テンプレート一覧のインポートから取り込む。カテゴリ **「手術」**
(code `9c4e1f37-8a52-4bd6-b071-3f8e2a5c9d14`)を拡張に持たせてある。

## 実施入力と重複させない線引き

構造化データは手術の実施入力(手術一覧の「実施」。`docs/surgery-result-design.md`)が
持つ。**このテンプレートには再入力しない。** 手術記録が持つのは、文章とシェーマでしか
残せない「所見と手技の経過」だけ。

| 実施入力(Procedure ハブ)が持つもの | ここに書かないこと |
|---|---|
| 実施術式の K/L コード(ハブ・子 Procedure) | 算定・NCD 向けの術式コード |
| performedPeriod・中間時刻 4 点 | 入退室・麻酔・執刀の時刻 |
| performer[](役割つきスタッフ) | 執刀医・助手・麻酔科医の列挙 |
| 出血量・尿量・輸血量(Observation) | 測定値 |
| 創分類・カウント(拡張)/ 転帰・合併症 | 分類値・合併症の有無 |
| 使用薬剤(MedicationAdministration)・材料(usedCode) | 請求に載る薬剤・材料 |

逆に、術中所見の記述・手技の時系列の経過・シェーマ・標本の肉眼所見は実施入力には
置き場が無く、ここが正本になる。術中トラブルの**経過**は「手技の経過」に書く
(**有無の要点**は実施入力の「合併症」欄が持つ)。

## 構成

| グループ | 項目 |
|---|---|
| 診断・術式 | 術前診断 / 術後診断 / 実施術式(正式名称) |
| 手術所見 | 術中所見 / シェーマ(描き込み) |
| 手技の経過 | 手技の経過 / ドレーン / 閉創 |
| 摘出標本・検体 | 摘出標本(肉眼所見) / 病理提出(→ ありなら提出検体と部位) / 培養提出 |
| 術後 | 術後方針 / 特記事項 |

- 各項目の意図は `designNote`(編集画面の「設計メモ」)に書いてある。
- **記入しなかった項目は記録に出ない。**
- 「病理提出の内容」は JASPEHR の制約(jsp-1 / jsp-9)どおり選択肢項目の直下の
  グループで出し分けている。病理検査のオーダーは別に出す(ここは記録)。
- ドレーンは「なし」と書かせる(空欄だと書き忘れと区別がつかない)。

## シェーマ

「シェーマ」は表示テキスト項目に `questionnaire-itemMedia`(台紙画像)を持たせたもので、
記入時に `SchemaPaintModal` で描き込み、合成画像が Binary + ローカル拡張
(`questionnaire-response-annotated-image`)として回答に保存される(診療記録の
シェーマと同じ機構)。

- 台紙は**人体の前面・背面**(汎用の線画。配布ファイルに base64 で埋め込み)。
- 術式に合った台紙(腹部臓器図など)にしたいときは、テンプレート編集でこの項目の
  画像を差し替えるか、術式別にテンプレートを複製して作る。シェーママスタは診療記録用で、
  テンプレートの台紙は各テンプレートが item ごとに持つ。

## 検証済みの内容

開発環境(2026-08-28)で以下を通した。

- インポートが上流 JASPEHR 検証を通る(itemMedia の base64 埋め込み込み。取り込みで
  台紙が Binary 化され、`Binary/<id>` 参照へ書き換わる)。配布ファイルは取り込み後に
  保存された形へ戻した正規形(再エクスポートしても差分が出ない)。
- カルテ →「テンプレート」→ 手術 → 手術記録で全項目記入。病理提出「あり」で
  条件付きグループが開く。シェーマの「編集」で台紙に描き込み → 保存。
- 登録するとタイムラインにテンプレートカードが出て、全項目の平文と描き込み済み
  シェーマのサムネイルが表示される(カードの日付は authored の UTC 日付で
  バケットされる既存挙動のとおり)。

## 将来の拡張

- **術式別テンプレート**: 台紙とチェック項目(例: 胆摘なら critical view of safety)を
  術式ごとに分ける。テンプレートを複製して作り、カテゴリ「手術」に足すだけでよい。
- **実施入力からの初期値**: 実施術式・スタッフを `initialExpression` で流し込めると
  二度書きが減るが、実行時コンテキストに手術オーダー・実施記録の変数が無いため
  現状は不可(`populateContext.ts` の拡張が要る)。
