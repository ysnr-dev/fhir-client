# 病理診断のシノプティックレポート(固形がん共通 TNM・大腸癌)

病理診断レポート(`docs/patho-order-design.md` §4.7)の「**診断**」に貼るテンプレート。取扱い規約・UICC TNM の項目を
選択肢で記録し、平文が診断欄に入る。院内がん登録(`docs/cancer-registry-design.md` §3)の形態コード・病期の初期値になる。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `patho-synoptic-tnm-01.questionnaire.json` | 病理診断 TNM(固形がん共通) | `PATHO_TNM_01` / `http://fhir-client.local/Questionnaire/patho-synoptic-tnm-01\|1.0.0` |
| `patho-synoptic-colon-01.questionnaire.json` | 病理診断 大腸癌(切除標本) | `PATHO_COLON_01` / `http://fhir-client.local/Questionnaire/patho-synoptic-colon-01\|1.0.0` |

レイアウト(`.tlf`)・マッピング定義は無し。テンプレート一覧のインポートから取り込む。カテゴリは
**「検査」**(code `25675b10-0ef3-4425-83c4-c1f8c3015cca`)。

## 使い方

病理レポートの「診断」(組織診・術中迅速)の「テンプレート」で選んで記入し、反映すると回答が平文になって診断欄に入る。
細胞診(判定 + 推定病変)には出ない。記入しなかった項目は診断の文面に出ない。既定テンプレートは無い(病理には検査項目マスタが
無いため。`docs/patho-order-design.md` §4.4)。

## 項目コード(`Questionnaire.item.code`)

院内がん登録が回答から値を拾うための項目コード。system は `http://fhir-client.local/CodeSystem/pathology-synoptic`。
施設がテンプレートを複製して直すときも、これらのコードと選択肢のコードは変えない(`fhir/cancerRegistryHelpers.ts` の
`SYNOPTIC_ITEM_CODES`)。

| コード | 項目 | 選択肢のコード | 院内がん登録への写し |
|---|---|---|---|
| `histologic-type` | 組織型 | 大腸: ICD-O-3 形態コード(「8211/3」、system `http://terminology.hl7.org/CodeSystem/icd-o-3`)。共通: 自由文 | [320] の上 5 桁(細胞型 + 性状) |
| `morphology-code` | ICD-O-3 形態コード(共通テンプレートの入力欄) | 「8140/3」の形 | 同上(組織型がコードを持たないとき) |
| `grade` | グレード・分化度 | `G1` `G2` `G3` `G4` `GX` | [320] の末尾 1 桁(G1〜G4 → 1〜4、それ以外 → 9) |
| `pt` / `pn` / `pm` | pT / pN / pM | 表記から p を除いたもの(`T3a` `N1a` `M1`) | [610] [620] [630] の 4 桁コード(`HBCR_PT_CODES` など) |
| `pstage` | 病期 | `IIIA` のような表記 | [600] の 4 桁コード |
| `neoadjuvant` | 術前治療 | `no` / `yes` | `yes` なら [600]〜[630] を 6620(術前治療後)、[680] を 660 |

[680] 進展度は pTNM からの機械的な読み替え(遠隔転移 440 > 領域リンパ節転移 420 > 上皮内 400 > T4 = 隣接臓器浸潤 430 >
限局 410)。部位ごとの規約の進展度と一致しないことがあるので、登録の画面で確かめて直す前提。

## 固形がん共通 TNM(PATHO_TNM_01)

腫瘍(原発部位・組織型・形態コード・グレード・最大径)→ 病理学的 TNM(術前治療・pT・pN・pM・病期)→ 脈管侵襲・断端
(ly・v・神経周囲浸潤・R 分類)→ 補足。pT〜病期の選択肢は UICC 第 8 版の共通の区分(亜分類は a〜c まで)。
臓器に固有の区分(乳癌の pT1mi、肺癌の pT1a〜c の径など)が要るときは臓器別のテンプレートを作る。

- pM0 は病理学的には確認できない分類だが、様式に「遠隔転移なし」を写すために置いてある。

## 大腸癌(PATHO_COLON_01)

大腸癌取扱い規約 第 9 版と UICC 第 8 版の項目。腫瘍(占居部位・最大径・肉眼型・組織型・分化度)→ 深達度・浸潤
(pT・ly・v・簇出・神経周囲浸潤)→ リンパ節(個数・pN)→ 遠隔転移・病期 → 断端(PM・DM・RM・R 分類)→ 補足。

- **組織型の選択肢のコードは ICD-O-3 の形態コード**。管状腺癌 tub1 / tub2 は同じ 8211/3 なので「管状腺癌」を選び、
  分化度(G1 = tub1、G2 = tub2)で分ける。低分化腺癌 por1 / por2 は 8140/3 + G3。
  ［要確認］がん登録のコーディングマニュアルが管状腺癌に 8140/3 を当てる運用なら選択肢のコードを直す。
- pT の表示は規約の深達度(M・SM・MP・SS/A・SE・SI/AI)を添えてある。pT1a / pT1b は SM 浸潤 1000µm 未満 / 以上。
