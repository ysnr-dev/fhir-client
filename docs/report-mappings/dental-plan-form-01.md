# 歯科疾患管理料に係る管理計画書 様式テンプレート

文書作成の「様式」(`../features/templates.md`「文書作成」)で使う、歯科疾患管理料の管理計画書。
紙面は厚生労働省の別紙様式 1(初回用)・別紙様式 2(継続用)(https://www.wic-net.com/material/static/00013628/00013628.pdf の
1・2 ページ)をそのまま 150dpi の画像にしたもの(A4 縦 1 ページ)。

| ファイル | 用途 |
|---|---|
| `dental-plan-form-01.pdf` | 元の様式(上の PDF の 1・2 ページだけを抜き出したもの) |
| `dental-plan-initial-form-01.json` | 初回用のエクスポートファイル(項目 62 件) |
| `dental-plan-continued-form-01.json` | 継続用のエクスポートファイル(項目 58 件) |
| `gen_dental_plan_form.py` | 上の 2 本の生成スクリプト。PDF を pypdfium2 で PNG にし、PDF の文字の座標(pt)から項目を置く(`pip install pypdfium2 pillow`) |

## 使い方

1. マスタメンテ > テンプレート > 文書テンプレートの「様式」タブ →「インポート」で 2 本の JSON を取り込む。
   カテゴリは「計画書」(code `20f88598-bea0-4280-8e85-24c639035e57`、無ければ名称)に引き当てる。
   どちらも無ければカテゴリ未設定で入るので、カテゴリ管理で作ってから編集で設定する。
2. 取り込んだ様式は無効で入るので、編集で有効にする。
3. カルテ右ペイン「文書作成」→「歯科疾患管理料に係る管理計画書（初回用）」または「（継続用）」で入力し、「作成」で PDF をファイルタブに保存する。

□ の位置や入力欄を直すときは `gen_dental_plan_form.py` の座標(pt)を直して再生成する(初回用と継続用で同じ部分は
`oral_status` などの共通の関数から作る)。

## 初期値

| 項目 | 初期値 |
|---|---|
| 記入日 | `%today`(和暦。雛形の「年 月 日」は塗りつぶし) |
| 患者氏名 | 漢字氏名 |
| 基礎疾患のチェック(初回用) | `%diagnosisIcd10` が 高血圧症 I10〜I13/I15・心血管疾患 I0/I2〜I5・呼吸器疾患 J4/J6/J8/J9(慢性下気道疾患など。急性の感染症は含めない)・糖尿病 E10〜E14・骨粗鬆症 M80/M81 で始まる |
| 服薬「有」・薬剤名(初回用) | `%activeMedications`(投与中の処方薬。1 行にするため改行を「、」に置換) |
| 口腔内の状況の歯式図 | `%oralExamChart`(最新の口腔診査の歯式図の画像。紙面の図は塗りつぶして重ねる) |
| 歯式図の下の 2 行 | `%oralExamSummary`(歯数のまとめ)と「むし歯 」+ `%oralCariesTeethList`(未処置歯の部位) |
| むし歯「有」/「無」 | `%oralCariesTeeth` が 0 より大きい / 0 と等しい(診査が無ければどちらも付かない) |
| 歯や歯肉の状態「その他」 | `%oralExamNote`(口腔診査の所見・特記事項。1 行に置換) |
| 医療機関名・担当歯科医師 | `%facilityName` / `%authorName` |

口腔診査の変数(`%oral...`)は患者の最新の口腔診査情報(`../features/oral-exam.md`)から入る。
4mm 以上の歯周ポケット・歯の動揺・歯肉の腫れ・プラーク・歯石の付着状況・口腔機能の問題は、口腔診査情報に
項目が無いので手入力(歯周組織検査のまとめ `PERIO_SUM_01`・口腔機能の検査 `ORAL_FUNC_01` とは結び付けていない)。

## 初回用と継続用の差

| | 初回用 | 継続用 |
|---|---|---|
| 基礎疾患・服薬・生活習慣・その他 | あり | — |
| これまでの治療 | — | あり |
| 治療の予定 | むし歯・ブリッジ・義歯・歯肉炎歯周炎・その他 | 上に加えて重症化予防(定期的な歯周病・むし歯・口腔機能の管理) |

## 紙様式との差分

- 紙面の歯式図は塗りつぶし、口腔診査の歯式図を同じアーチ状の配列(円の位置・大きさは紙面と同じ。乳歯は内側)で画像にして重ねる。
  歯の色・歯面・ブリッジ・義歯の線はカルテの歯式図と同じで、歯の外側に番号、内側に健診記号(健全歯の「／」は書かない)と略号、中央の「（ ）本」に現在歯数が入る。
- 「（ ）回目」のような回数欄は様式に無いのでそのまま。
