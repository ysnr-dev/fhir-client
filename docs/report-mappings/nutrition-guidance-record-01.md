# 栄養指導 指導記録テンプレート

栄養指導の実施入力の「**指導内容**」欄に貼る汎用テンプレート。自由文だけで書くと、
次回の指導者が「前回どこまで話して、患者が何をどこまで理解したか」を辿れない。
継続指導で引き継ぐべき項目を並べてある。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `nutrition-guidance-record-01.questionnaire.json` | 栄養指導 指導記録 | `NUTGUIDE_REC_01` / `http://fhir-client.local/Questionnaire/nutrition-guidance-record-01\|1.0.0` |

レイアウト(`.tlf`)・マッピング定義は無し(帳票出力は対象外)。テンプレート一覧の
インポートから取り込む。カテゴリ **「栄養指導」** を拡張に持たせてある
(このテンプレートのために新設したカテゴリ)。

> **取り込む前に**: JSON の `questionnaire-template-category` 拡張の
> `valueCoding.code` はプレースホルダ(`00000000-...`)にしてある。code は環境ごとに
> 違うので、取り込む環境の `questionnaire_categories` に「栄養指導」カテゴリを作り、
> その code へ差し替えてから取り込むこと(他科依頼テンプレートと同じ運用)。

## 使い方

栄養指導一覧 → 実施 の「指導内容」欄で「テンプレート」を押し、`栄養指導` カテゴリから
選ぶ。記入して反映すると、回答が平文になって指導内容欄に入る。他科依頼の依頼目的・
放射線の特別指示と同じ作りで、

- テンプレート紐付き中は欄を直接編集できない(回答と本文が食い違うため)。
  直すときは「テンプレート編集」から
- 「解除」で紐付けだけ外れ、記載された文言は残る
- **記入しなかった項目は出力に現れない。** 当てはまる欄だけ埋めればよい

回答は QuestionnaireResponse として残り、実施記録(Procedure)のローカル拡張
`nutrition-guidance-record` から参照される
(`docs/nutrition-guidance-order-design.md` §4.2)。実施を取り消すと、この回答も
同じ transaction で消える(参照元が無い回答を残さないため)。

## 項目

| グループ | 項目 | 意図 |
|---|---|---|
| 栄養評価 | 食事摂取状況 / 身体計測 / 参考にした検査値 | 指導の前提。継続指導では前回からの変化が読み取れるように書かせる |
| 指導内容 | 指導した項目(複数選択) / 指導の内容 / 患者と決めた目標 | 「何を説明したか」と「患者が何をすることにしたか」を分ける。目標は次回の出発点になる |
| 理解度・次回 | 理解度 / 患者の反応・訴え / 次回の予定 | 次の指導者が「どこから話すか」を決める手がかり。日時そのものは予約で持つので書かせない |
