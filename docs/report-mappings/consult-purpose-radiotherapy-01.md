# 他科依頼 放射線治療依頼テンプレート

放射線治療科あての他科依頼で「**依頼目的**」欄に貼るテンプレート。臨床医から放射線治療医への
診察依頼は他科依頼オーダーで出す(`docs/radiotherapy-order-design.md` §1.2)。依頼医は
線量・照射技法を決めない — それは放射線治療医が書く治療処方の仕事で、ここでは適応の判断に
要る情報を漏らさず伝える。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `consult-purpose-radiotherapy-01.questionnaire.json` | 他科依頼 放射線治療依頼 | `CONSULT_RT_01` / `http://fhir-client.local/Questionnaire/consult-purpose-radiotherapy-01\|1.0.0` |

作りと使い方は汎用版(`consult-purpose-01.md`)と同じ。カテゴリ「他科依頼」の code は環境ごとに
違うので、別環境へ入れるときは差し替える。

## 依頼先を選ぶと自動で開くようにする

「管理 > 自院設定 > 他科依頼の既定テンプレート」で、診療科「放射線治療科」にこのテンプレートを
選んで保存する(`facility_settings.settings.consult_default_templates`。キーは診療科の
Organization.id なので環境ごとに設定し直す)。依頼先にその科を選んで「テンプレート」を押すと、
このテンプレートが選択済みで開く。

## 項目

| グループ | 項目 | 意図 |
|---|---|---|
| 治療の対象 | 原発部位 / 治療対象部位 / 左右 / 治療目的 / 依頼の内容 | 治療目的は依頼医の見立て。確定は治療処方で行う |
| 臨床情報 | 病期 / 病理診断 / 画像所見 / 経過の要点 / 症状 / PS | 適応と目的(根治か緩和か)を決める材料 |
| 併用治療 | 併用治療(複数選択) / 内容と時期 | 同時化学放射線療法は開始日の調整が要る |
| 過去の放射線治療 | 有無 / 照射部位 / 治療時期 / 治療施設 / 総線量・回数 | 再照射は線量の上限を左右する。「あり」のときだけ詳細欄が出る(`enableWhen`)。他院での照射歴はここが唯一の入口 |
| 注意事項 | 該当するもの(複数選択) / 内容 | ペースメーカー・ICD、照射野の金属、妊娠の可能性、計画 CT の造影に関わるもの |
| 希望・患者への説明 | 希望開始時期 / 患者への説明 / 特記事項 | 緊急照射(脊髄圧迫・上大静脈症候群)は「至急」で伝える |

治療処方の画面では、紐付けた依頼の依頼目的(この平文)がそのまま表示される
(`docs/radiotherapy-order-design.md` §2.5)。

## JASPEHR の制約

`choice` の項目には `questionnaire-itemControl` 拡張が必須(jsp-6)。`name` は 15 文字以内(jsp-5)。`enableWhen` を持てるのは `choice` 項目の子だけ(jsp-9)なので、治療歴の詳細は「過去の放射線治療」の子項目にしてある。単一選択は `radio-button`、
複数選択は `check-box`。
