# 特定抗菌薬 届出書・AST 回診記録テンプレート

抗菌薬適正使用支援(AST、`docs/antimicrobial-stewardship-design.md`)で使うテンプレート 2 本。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `ast-notify-01.questionnaire.json` | 特定抗菌薬 届出書 | `AST_NOTIFY_01` / `http://fhir-client.local/Questionnaire/ast-notify-01\|1.0.0` |
| `ast-round-01.questionnaire.json` | AST 回診記録 | `AST_ROUND_01` / `http://fhir-client.local/Questionnaire/ast-round-01\|1.0.0` |

レイアウト(`.tlf`)・マッピング定義は無し。テンプレート一覧のインポートから取り込む。カテゴリは持たせていない
(取り込んだあとに施設のカテゴリを付ける)。

## 届出書(`AST_NOTIFY_01`)

特定抗菌薬(薬剤付加情報の「特定抗菌薬」が届出制・許可制の薬)を含む処方・注射を登録すると、依頼医に
「特定抗菌薬の届出」の通知が届く。**抗菌薬適正使用の一覧(`/ast-worklist`)の「届出」タブ**の行から開いて書く。
保存すると回答がオーダーに `basedOn` で結ばれ、同じ transaction で通知が閉じる(許可制は「許可待ち」になり、
AST チームの構成員が「許可」を押すと閉じる)。

| グループ | 項目 | 意図 |
|---|---|---|
| 感染症 | 感染症名 / 感染臓器 / 起因菌 / 培養の提出 | 使う理由の確認。培養を出さずに広域抗菌薬を始めていないか |
| 使用計画 | 選択理由 / 投与予定日数 / TDM / 備考 | 長期投与・TDM の要否を AST が追う材料 |

## AST 回診記録(`AST_ROUND_01`)

マスタメンテ > 共通 > チーム医療のチームで、区分「抗菌薬適正使用(AST)」のチームの回診記録テンプレートに設定する。
チーム依頼一覧の回診記録から書く。

| グループ | 項目 | 意図 |
|---|---|---|
| 状況 | 使用中の抗菌薬・投与量 / 腎機能 / 培養・感受性 / 評価 | 介入の根拠 |
| 提案 | 提案(継続・de-escalation・変更・中止・投与量・検査・TDM) / 内容 / 主治医の受け入れ / 次回介入の予定日 | 介入の結果を集計できる形で残す |
