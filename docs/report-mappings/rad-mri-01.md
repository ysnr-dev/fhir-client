# MRI検査 安全確認・特別指示テンプレート

放射線オーダーの GP 単位の欄「**特別指示**」に貼るテンプレート。MRI は強い磁場の中に入る検査で、
体内金属・植込み機器・刺青・閉所恐怖・妊娠の可能性を撮影前に確かめないと撮れない。患者ごとに
変わる確認事項は JJ1017 の特殊指示(別表6B、2 桁 × 1 個)では表せないので、CT
(`rad-ct-01.md`)と同じくテンプレートで受ける(`docs/rad-backlog.md` B-2)。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `rad-mri-01.questionnaire.json` | MRI検査 安全確認・特別指示 | `RAD_MRI_01` / `http://fhir-client.local/Questionnaire/rad-mri-01\|1.0.0` |

レイアウト(`.tlf`)・マッピング定義は無し。テンプレート一覧のインポートから取り込む。カテゴリは
CT と同じ **「検査」**。MRI の撮影項目マスタ(`/rad-items` の「既定のテンプレート」→ 特別指示)に
設定しておけば、項目を選んだ時点で選択済みになる。

## 構成

| グループ | 項目 |
|---|---|
| MRI 安全確認 | ペースメーカー・ICD(→条件付き対応なら機種・手配) / 体内金属・植込み機器(→ありなら種類・部位・MRI 対応の確認) / 金属片の可能性 / 刺青・アートメイク / 貼付剤 / 閉所恐怖 / 妊娠の可能性 |
| 撮影範囲・撮影条件 | 撮影範囲 / 追加のシーケンス・撮影条件 / 磁場強度 |
| 造影 (造影なし・造影あり) | ↓「造影あり」のときだけ開く |
| └ 造影の指示 | 造影剤 / 投与量 / 撮影のタイミング / 造影剤の安全確認(ガドリニウム造影剤の副作用歴・透析・同意) |
| 前処置・患者準備 | 食事(→絶食なら何時間前) / 休薬・当日内服の指示 / ルート確保 |
| 患者状態・搬送 | 搬送方法 / 鎮静 / 意思疎通・体位保持 / 付き添い / 持ち込む機器 |
| 読影・報告 | 読影 / 報告の希望日 / 比較したい過去検査 |
| (最後) | その他の申し送り |

- **安全確認を先頭に置く**。CT は造影の指示が主役だが、MRI は「撮影室に入れてよいか」が先に来る。
- 条件付きの枝は CT と同じく選択肢項目の直下のグループで作る(JASPEHR の jsp-1 / jsp-9)。
- 各項目の意図は `designNote` に書いてある。

## オーダー画面の自動表示との分担

オーダー画面は、カルテの記録から次を自動で出す(`components/RadSafetyNotice.tsx`)。

- MRI の項目を選んだとき: 注意区分「体内金属・ペースメーカー」(`implant`)
- 造影の項目を選んだとき: 注意区分「造影剤注意」、造影剤アレルギー、eGFR、ビグアナイド系の内服

テンプレートの安全確認は、自動では分からないもの(機種と MRI 対応の可否、刺青・貼付剤・閉所恐怖、
他院での副作用歴、同意)を依頼医が書く欄。CT の安全確認欄と違い、eGFR とビグアナイド系の欄は置いていない。

## 項目コード(item.code)を入れていない理由

CT と同じ。確度の高い標準コードが見当たらないので付けず、回答から Observation も生成しない。
