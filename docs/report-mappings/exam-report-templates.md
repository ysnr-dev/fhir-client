# 所見レポートのテンプレート(心電図・上部内視鏡・大腸内視鏡)

生理検査・内視鏡の所見レポート(`docs/exam-report-design.md`)の「**所見**」に貼るテンプレート。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `physio-ecg-report-01.questionnaire.json` | 心電図 所見 | `PHY_ECG_RPT_01` / `http://fhir-client.local/Questionnaire/physio-ecg-report-01\|1.0.0` |
| `endoscopy-egd-report-01.questionnaire.json` | 上部内視鏡 所見 | `END_EGD_RPT_01` / `http://fhir-client.local/Questionnaire/endoscopy-egd-report-01\|1.0.0` |
| `endoscopy-cs-report-01.questionnaire.json` | 大腸内視鏡 所見 | `END_CS_RPT_01` / `http://fhir-client.local/Questionnaire/endoscopy-cs-report-01\|1.0.0` |

レイアウト(`.tlf`)・マッピング定義は無し。テンプレート一覧のインポートから取り込む。カテゴリは
**「検査」**(code `25675b10-0ef3-4425-83c4-c1f8c3015cca`)。

## 使い方

検査項目マスタ(`/physio-items`・`/endoscopy-items` の編集モーダル「既定のテンプレート」→ 所見)に設定しておくと、
所見レポートの「所見」の「テンプレート」でそれが最初から開く。記入して反映すると回答が平文になって所見欄に入る。
**記入しなかった項目は出力に現れない。**

開発環境では、心電図12誘導(生理 000001)に `PHY_ECG_RPT_01`、内視鏡の上部(種別 01)の全項目に
`END_EGD_RPT_01`、大腸(種別 03)の全項目に `END_CS_RPT_01` を設定してある。

判定・診断はレポートの「判定」「診断」欄に書く(テンプレートには持たない)。

## 心電図(PHY_ECG_RPT_01)

調律・心拍数 → 電気軸 → 間隔(PR・QRS・QT・QTc)→ 異常所見(伝導障害・期外収縮・ST-T・Q波・電位)の順。
判読の手順に合わせた並び。異常所見は当てはまるものを複数選び、誘導や前回との比較は「補足」に書く。

## 上部・大腸内視鏡(END_EGD_RPT_01 / END_CS_RPT_01)

| 群 | 項目 | 由来 |
|---|---|---|
| 検査時情報 | 挿入経路(上部)・到達部位(大腸)・挿入時間(大腸)・腸管前処置(大腸)・鎮痙剤使用・鎮静・鎮痛・麻酔・送気・観察範囲(上部)・画像強調観察 | JED 用語集[基本情報] Ver.5.0.3 の統一表記を転記 |
| 部位別所見 | 上部: 咽頭・食道・胃・十二指腸 / 大腸: 回腸・盲腸・結腸・直腸・肛門 | 自由文 |
| 処置 | 生検(あり → 個数・部位) | - |
| 偶発症 | 手技中偶発症(あり → 種類・対応・転帰) | JED 用語集[基本情報] |

- 鎮静の「BZD」は、JED の表記 BZP が BZD に改められた後の表記(END_EGD_01 と同じ)。
- 偶発症を「なし / あり」の 2 択にして、種類・対応・転帰を「あり」の下に置いたのは、表示条件を選択肢の直下の
  グループにしか付けられない(jsp-1 / jsp-9、条件は `=` のみ)ため。JED では種類ごとに対応・転帰を持つが、
  1 回の検査で偶発症が 2 種類以上起きることはまれなので 1 組にした。
- 所見の質的診断(JED 診断処置用語)は手元に用語集が無いため選択肢にしていない。取り寄せたら改版する
  (`docs/exam-report-design.md` §6-2)。
- 数値の単位は、テンプレートのインポートが code と表示を同じ値にそろえるため、表示の文字列(個・分・回/分・ms)を
  code にしてある(`oral-function-01` と同じ)。
