# 上部内視鏡 前処置・鎮静指示テンプレート

内視鏡オーダーの GP 単位の欄「**特別指示**」に貼るテンプレート。上部内視鏡は検査項目を
選ぶだけでは検査室が動けない(絶食・抗血栓薬・鎮静・同意の確認が毎回変わる)ため、
訊く項目を決めてテンプレートにした。放射線の `rad-ct-01`(CT特別指示)と同じ位置づけ。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `endoscopy-egd-01.questionnaire.json` | 上部内視鏡 前処置・鎮静指示 | `END_EGD_01` / `http://fhir-client.local/Questionnaire/endoscopy-egd-01\|1.0.0` |

レイアウト(`.tlf`)・マッピング定義は無し(帳票出力は対象外)。テンプレート一覧のインポートから
取り込む。カテゴリ **「検査」**(code `25675b10-0ef3-4425-83c4-c1f8c3015cca`)を拡張に持たせてある。

## 使い方: 内視鏡オーダーの「特別指示」に貼る

内視鏡オーダー画面(カルテ→内視鏡)の GP ごとの **特別指示** 欄で「テンプレート」を押し、
`検査` カテゴリから選ぶ。記入して反映すると、回答が平文になって特別指示欄に入る。

上部の検査項目マスタ(`/endoscopy-items` の編集モーダル「既定のテンプレート」→ 特別指示)に
このテンプレートを設定しておけば、その項目を選んだ時点で選択済みになる。運用ではこちらを
勧める(依頼医がテンプレートを探さなくて済む)。

**記入しなかった項目は出力に現れない。** 当てはまる欄だけ埋めればよい。絶食の開始と
鎮静の薬剤は、それぞれの前提(絶食「指示済」/鎮静「希望あり」)を選ぶまで表示されない。

出力例(鎮静希望・アスピリン休薬):

```
【前処置・患者準備】
  絶食指示: 指示済
    【絶食】
      絶食の開始: 前日21時から
  挿入経路の希望: 経口
【抗血栓薬】
  服用状況と指示: あり(休薬指示済)
  薬剤名: バイアスピリン
  休薬・置換の内容: 3日前から休薬
【鎮静・鎮痛】
  鎮静: 希望あり
    【鎮静の指示】
      薬剤: BZD
      帰宅時の付き添い・車運転不可の説明: 説明済
  咽頭麻酔: あり
【同意・その他】
  検査同意書: 取得済
```

条件で出し分ける欄が「絶食」「鎮静の指示」というグループの中に入っているのは、
JASPEHR プロファイルの制約(jsp-1 / jsp-9: 表示条件は選択肢項目の直下のグループにしか
付けられない)による。選択肢項目には必ず描画形式を指定する(jsp-6)。

## JED 用語との対応

選択肢のうち JED 用語集[基本情報]に対応する項目は、JED の統一表記をそのまま転記してある。

| テンプレートの欄 | JED 基本情報の項目 | 転記した用語 |
|---|---|---|
| 挿入経路の希望 | 挿入経路(上部) | 経口 / 経鼻 / 経瘻孔・その他 |
| 鎮静の薬剤 | 鎮静・鎮痛・麻酔 | BZD / 鎮痛薬 / プロポフォール / DEX / 全身麻酔 |
| 抗血栓薬 | 抗血栓薬 | 分類名(アスピリン・ワルファリン等)を薬剤名欄の記載に使う |

JED 用語は専用のマスタを持たず、テンプレートの選択肢への転記だけで供給する
(検査目的は `endoscopy-purpose.md` の END_*_PUR_01 系を参照)。用語の版が上がったら
テンプレートを改版して取り込み直す(canonical のバージョンを上げる)。

## この線引きの理由

- **オーダー項目(何を検査するか)** は検査項目マスタが持つ。ここには書かない。
- **検査目的** はオーダーの検査目的欄(END_*_PUR_01 テンプレート)が持つ。ここには書かない。
- **検査時情報・偶発症**(実際に使った鎮静剤・到達部位・偶発症)は実施側の記録であり、
  将来のレポート機能(JED 診断処置用語)の範囲。このテンプレートは「依頼時点の指示」だけを扱う。
