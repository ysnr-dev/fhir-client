# 感染症 発生届(共通項目)テンプレート

感染症法 第 12 条の発生届(全数把握の感染症)の共通項目。感染症の発生届の一覧(`docs/infectious-disease-report-design.md`)から、
届出対象の病名を対象プロブレムに選んで記入する。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `idsc-notify-01.questionnaire.json` | 感染症 発生届(共通項目) | `IDSC_NOTIFY_01` / `http://fhir-client.local/Questionnaire/idsc-notify-01\|1.0.0` |

レイアウト(`.tlf`)・マッピング定義は無し(届出様式は疾患ごとに違うため)。テンプレート一覧のインポートから取り込む。
カテゴリは **「検査」**(code `25675b10-0ef3-4425-83c4-c1f8c3015cca`)。

## 構成

| 群 | 項目 |
|---|---|
| 感染症 | 感染症名・類型・届出の区分(患者 / 無症状病原体保有者 / 疑似症患者 / 死体)・届出期限 |
| 患者 | 氏名・性別・生年月日・年齢・住所・電話番号・職業 |
| 診断 | 症状・診断方法(検査方法・検体・結果)・初診年月日・診断(検案)年月日・発症年月日・感染したと推定される年月日・死亡年月日・入院の有無と入院先 |
| 感染原因・感染経路・感染地域 | 感染経路・感染地域(国内 / 国外)と詳細・感染原因 |
| 届出 | 診断した医師・医療機関名・所在地・電話番号・届出先保健所・**届出状況(未届出 / 届出済)**・届出方法・届出年月日・その他 |

- **届出状況(`idn_status`)と届出年月日(`idn_notify-date`)の linkId は変えない**。発生届の一覧が「届出済」の判定と届出日の表示に使う
  (`fhir/infectiousDiseaseReportHelpers.ts`)。
- 氏名・住所は五類の一部(梅毒・後天性免疫不全症候群・ウイルス性肝炎など)では届け出ない。初期値は入るので、該当するときは空にする。

## 初期値

| 項目 | 初期値 |
|---|---|
| 感染症名・類型・届出期限・診断年月日 | `%notifiableDiseaseName` `%notifiableDiseaseClass` `%notifiableDueDate` `%notifiableDiagnosisDate`(対象プロブレムの病名から) |
| 氏名・性別・生年月日・年齢・住所・電話番号 | 患者情報 |
| 死亡年月日 | `%deathDate` |
| 入院先医療機関 | 入院中なら自院の名称 |
| 診断した医師・医療機関名・所在地・電話番号 | ログイン中の医療従事者・施設設定の自院 |
| 届出状況 | 未届出 |
| 届出年月日 | 記入を始めた日 |

## 検証(2026-10-25、開発環境)

- 発生届の一覧の「届出」から開いた回答に、感染症名(腸管出血性大腸菌感染症)・類型(三類)・届出期限・診断年月日・患者・
  医療機関・医師が入ること。届出状況を「届出済」にして確定すると一覧が「届出済」になること。
