# 麻酔記録テンプレート

麻酔担当医が退室後に書く麻酔記録(サマリー)のテンプレート。手術記録(`sur-op-01.md`)と
同じく、カルテの「テンプレート」から記入する単独のテンプレートカード方式。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `sur-anes-01.questionnaire.json` | 麻酔記録 | `SUR_ANES_01` / `http://fhir-client.local/Questionnaire/sur-anes-01\|1.0.0` |

レイアウト(`.tlf`)・マッピング定義は無し。テンプレート一覧のインポートから取り込む。
カテゴリ **「手術」**(code `9c4e1f37-8a52-4bd6-b071-3f8e2a5c9d14`)を拡張に持たせてある。

## サマリー方式にした理由(麻酔チャートは対象外)

本来の麻酔記録は 5 分毎のバイタルサインを打点するチャートで、テンプレート機構
(設問と回答)では表現できない。術中のリアルタイム記録は将来の専用機能
(`docs/surgery-result-design.md` §8-1 の第3段階)と割り切り、ここは**退室後に
まとめて書く要約**に徹する。「術中経過」は血圧・脈拍・SpO2 の推移の要約と介入した
イベントを時刻付きで書く欄で、チャートの代わりにはならないが、次に麻酔をかける人が
読む記録としては要点が揃う。

## 実施入力・申込と重複させない線引き

| よそが持つもの | ここに書かないこと |
|---|---|
| 実施入力の performedPeriod・中間時刻 4 点 | 入退室・麻酔開始/終了の時刻 |
| 実施入力の Observation | 出血量・尿量・輸血量 |
| 実施入力の実施術式(L 章の麻酔手技料) | 算定用の麻酔コード |
| 申込ヘッダの麻酔方法・麻酔科管理(拡張) | 予定時点の麻酔情報 |

輸液(In 側)・術中使用薬剤の**使い方**はここに書く。算定に載せる薬剤は実施入力の
使用薬剤にも入れる(designNote に明記)。

## 構成

| グループ | 項目 |
|---|---|
| 術前評価 | ASA-PS(1〜5) / 緊急(E) / 術前評価の要点 |
| 麻酔法 | 麻酔法(チェックボックス複数・併用) / 区域麻酔の手技 |
| 気道・導入 | 気道確保 / チューブ・デバイス / 喉頭展開(Cormack-Lehane) / 喉頭鏡・補助器具 / 困難気道(→ ありなら内容と対応) / 導入 |
| 維持 | 維持 / 筋弛緩と拮抗 / 呼吸管理 |
| 術中経過 | 術中経過 / 輸液 / 循環作動薬 |
| 覚醒・退室 | 覚醒・抜管 / 退室時の気道 / 退室先 / 術後鎮痛 / 申し送り |

- **ASA-PS を入れている理由**: 麻酔科の術前診察ワークフローは「今は持たない」と
  決めたもの(surgery-result-design §8-4)だが、ASA-PS は麻酔記録の定型の一部でも
  あるので、記録の要約としてここに持つ。術前診察ワークフローができたらそちらが正本。
- **困難気道は次回の麻酔に引き継ぐ最重要情報**なので、条件付きの枝で具体的に
  書かせる(換気困難/挿管困難の別・試行回数・最終的に確保した手段)。
- 麻酔法はチェックボックス(複数選択)。併用麻酔(全麻 + 硬膜外 など)をすべて
  チェックする。
- 区域麻酔の手技は条件付きの枝にしていない。表示条件は「選択肢 1 つの一致」しか
  書けず(jsp-1: enableWhen 最大 1 件・"=" のみ)、脊麻/硬膜外/ブロックのどれでも
  開く枝が作れないため、常に出して未記入なら出力に現れない仕様に頼る。

## 検証済みの内容

開発環境(2026-08-28)で以下を通した。

- インポートが上流 JASPEHR 検証を通る。配布ファイルは取り込み後に保存された形へ
  戻した正規形。
- カルテ →「テンプレート」→ 手術 → 麻酔記録で記入(ASA-PS・緊急 E・麻酔法
  チェックボックス・気道確保・Cormack 分類・退室時の気道・退室先のラジオ、
  自由記載欄)。登録するとテンプレートカードに全文が出る。

## 将来の拡張

- **麻酔チャート**: **実装済み**(`docs/anesthesia-chart-design.md`。手術一覧から
  開く専用ページ)。チャートが術中の事実の記録、このテンプレートが考察と申し送り、
  という役割分担になった。生体情報モニタとの接続はチャート側の申し送り。
- **術前診察テンプレート**: 麻酔科ワークフローを作るとき、術前評価(気道評価・
  ASA-PS・同意)を独立したテンプレートまたは画面に切り出し、この記録の「術前評価」
  グループは参照へ置き換える。
