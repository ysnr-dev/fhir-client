# 放射線治療 週次レビューテンプレート

照射期間中の診察(週次レビュー)の様式。放射線治療は数週間続き、そのあいだ放射線治療医が
週に 1 回ほど患者を診て、皮膚や粘膜の状態・体重・全身状態を見ながら治療を続けられるかを
判断する。記録を自由文だけで残すと「そのコースの診察」を集められず、診察が空いたことに
気づけないので、**テンプレート回答を治療処方に結んで残す**
(`docs/radiotherapy-order-design.md` §6.3)。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `radiotherapy-review-01.questionnaire.json` | 放射線治療 週次レビュー | `RT_REVIEW_01` / `http://fhir-client.local/Questionnaire/radiotherapy-review-01\|1.0.0` |

レイアウト(`.tlf`)・マッピング定義は無し(帳票出力は対象外)。テンプレート一覧のインポートから
取り込む。カテゴリ **「放射線治療」**(code `c8f5a301-6d24-4b9e-8f07-1a3e5c7b9d20`)を拡張に
持たせてある。カテゴリの code は環境ごとに違うので、別環境へ入れるときは差し替える
(カテゴリが無ければ先に「管理 > テンプレートカテゴリ」で作る)。

## 使い方: 治療処方のカードから開く

カルテの放射線治療(治療処方)カードのメニュー **「週次レビュー」** を押すと、右ペインに
そのコースの診察が並び、その下にテンプレートの記入欄が出る。保存すると回答が治療処方に
`basedOn` で結ばれ、部門一覧(放射線治療カレンダー)のコースに最後の診察日が出る。

**2 回目からは前回と同じテンプレートが選択済みで開く。** プルダウンから探し直さなくてよい。

## 項目

| グループ | 項目 | 意図 |
|---|---|---|
| 全身状態 | Performance Status / 体重 / 食事摂取 | 治療を続けられるかの土台。頭頸部・食道では体重の減りが判断を左右する |
| 照射野・症状の確認 | 照射野の皮膚 / 粘膜炎 / 自覚症状 / 診察所見・検査結果 | 照射部位ごとに見る場所は違うが、皮膚と粘膜はどの部位でも確認する |
| 判断 | 治療継続の判断 / 対応・指示 / 次回診察の予定 | 「診たが問題なかった」ことも記録として残す。休止・中止の操作そのものは部門一覧で行う |

## 有害事象との使い分け

Grade を付けて経過を追うものは、この様式ではなく **「有害事象」**(カードのメニュー →
有害事象)に記録する。CTCAE 用語 + Grade + 発現日〜回復日で持ち、コースの詳細と終了サマリーに
そのまま出る。週次レビューは「その日に診て、どう判断したか」を残すもので、役割が違う。
