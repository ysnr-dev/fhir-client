# 診療情報提供書 Word テンプレート

文書作成の「Word / Excel」(`../features/templates.md`「文書作成」)で使う診療情報提供書。
項目立ては様式版(`referral-form-01.md`)と同じで、別紙様式 11 に合わせた A4 縦 1 ページ。
作成時にカルテの値を差し込んだ .docx を患者ファイルに保存してダウンロードし、続きは Word で書く。

| ファイル | 用途 |
|---|---|
| `referral-word-01.docx` | テンプレート本体 |
| `gen_referral_docx.py` | 上の .docx の生成スクリプト(Python 標準ライブラリだけで OOXML を組む) |

## 使い方

1. マスタメンテ > テンプレート > 文書テンプレートの「Word / Excel」タブ →「新規登録」で
   `referral-word-01.docx` を選び、カテゴリ「紹介状」で登録する。
2. カルテ右ペイン「文書作成」→ このテンプレートを選び、差し込む値を確かめて「作成」。
3. ダウンロードした .docx に紹介先・紹介目的・治療経過などを書き、「ファイル」タブの「差し替え」で戻す。

様式を直すときは `gen_referral_docx.py` を直して再生成する。Word で直接編集して保存してもよいが、
その場合はスクリプトと食い違うので、以後は .docx の方を正とする。

## プレースホルダー

| 場所 | プレースホルダー |
|---|---|
| 作成日 | `{{今日の日付(和暦)}}` |
| 紹介元 | `{{医療機関郵便番号}}` `{{医療機関住所}}` `{{医療機関名}}` `{{医療機関電話番号}}` `{{作成者氏名}}` |
| 患者 | `{{患者氏名(漢字)}}` `{{性別}}` `{{住所}}` `{{電話番号}}` `{{生年月日(和暦)}}` `{{年齢}}` |
| 傷病名 | `{{傷病名(継続中・全区分)}}` |
| 既往歴及び家族歴 | `{{既往歴}}` |
| 症状経過及び検査結果 | `{{最新の検査結果}}` |
| 現在の処方 | `{{投与中の処方薬}}` |

紹介先・職業・紹介目的・治療経過・備考は空欄で、Word で書く。

## 作りの要点

- 本文の欄は表の行の最小の高さだけを決めている。差し込んだ値や追記が多いと行が伸び、2 ページ目に続く。
- 段落の行間は文字サイズの 1.4 倍の固定値。游明朝の既定の行間では 1 ページに収まらないため。
- 宛先の記入欄は全角空白に下線を引いたもの。Word で書き込むときは空白を上書きする。
