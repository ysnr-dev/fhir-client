# 診療情報提供書 様式テンプレート

文書作成の「様式」(`../features/templates.md`「文書作成」)で使う診療情報提供書。
紙面は診療報酬の別紙様式 11 の項目立てに合わせて本アプリ用に起こしたもの(A4 縦 1 ページ)。
テンプレート + ThinReports 帳票で出す版は `referral-01.md`。

| ファイル | 用途 |
|---|---|
| `referral-form-01.json` | 様式テンプレートのエクスポートファイル(ページ画像 PNG と項目の配置) |
| `gen_referral_form.py` | 上の JSON の生成スクリプト。紙面を HTML で組み、Chrome のヘッドレスで 1240x1754px(150dpi)の PNG にする |

## 使い方

1. マスタメンテ > テンプレート > 文書テンプレートの「様式」タブ →「インポート」で `referral-form-01.json` を選ぶ。
   カテゴリは「紹介状」(code `1c504eb2-1abb-426a-810f-5102cae33628`、無ければ名称)に引き当てる。
2. 取り込んだ様式は無効で入るので、編集で有効にする。
3. カルテ右ペイン「文書作成」→「診療情報提供書」で入力し、「作成」で PDF をファイルタブに保存する。

紙面や配置を直すときは `gen_referral_form.py` を直して再生成する(罫線と項目は同じ座標表から作る)。
取り込み済みの様式に反映するには、デザイナで直すか、取り込み直して古い方を消す。

## 紙様式との差分

- 性別の「男・女」の丸囲み、生年月日の元号の丸囲みは、選択項目と和暦の印字に置き換えた。
- 「印」欄は紙面に残すだけで、押印・電子署名は扱わない。
