# 主治医意見書 様式テンプレート

文書作成の「様式」(`../features/templates.md`「文書作成」)で使う介護保険の主治医意見書。
紙面は厚生労働省の様式の項目立てに合わせて本アプリ用に起こしたもの(A4 縦 2 ページ、項目 238 件)。

| ファイル | 用途 |
|---|---|
| `care-opinion-form-01.json` | 様式テンプレートのエクスポートファイル(ページ画像 PNG 2 枚と項目の配置) |
| `gen_care_opinion_form.py` | 上の JSON の生成スクリプト。紙面を HTML で組み、Chrome のヘッドレスで 1240x1754px(150dpi)の PNG にする |

## 使い方

1. マスタメンテ > テンプレート > 文書テンプレートの「様式」タブ →「インポート」で `care-opinion-form-01.json` を選ぶ。
   カテゴリは「診断書・意見書」(code `dfd54cf2-2490-4936-a171-6049627ca3f3`、無ければ名称)に引き当てる。
   どちらも無ければカテゴリ未設定で入るので、カテゴリ管理で作ってから編集で設定する。
2. 取り込んだ様式は無効で入るので、編集で有効にする。
3. カルテ右ペイン「文書作成」→「主治医意見書」で入力し、「作成」で PDF をファイルタブに保存する。

紙面や配置を直すときは `gen_care_opinion_form.py` を直して再生成する。文字・□・入力欄は同じ座標計算(`Flow`)で置くので、
チェック項目は必ず□の上に乗る。1 ページ目は余白がほとんど無く、行を足すとスクリプトの assert で止まる。

## 初期値

| 項目 | 初期値 |
|---|---|
| 記入日・最終診察日 | `%today`(和暦) |
| 申請者(ふりがな)・氏名 | カナ氏名 / 漢字氏名 |
| 生年月日・年齢 | `%patient.birthDate`(和暦) / `%age` |
| 郵便番号・住所・連絡先 | 患者の住所の 1 件目 / 電話番号 |
| 医師氏名・医療機関名・所在地・電話・FAX | `%authorName` / `%facilityName` / `%facilityAddress` / `%facilityPhone` / `%facilityFax` |
| 身長・体重 | `%bodyHeight` / `%bodyWeight` |
| 感染症(具体的に) | `%infections` |

診断名 1〜3 は転記(病名)、「傷病の経過及び治療内容」と「特記すべき事項」は転記(処方・注射・オーダー・病名・検査結果)を付けている。

## 紙様式との差分

- 選択肢はすべてチェック項目で、択一の制御はしない(紙と同じく 2 つに印を付けられる)。
- 性別・生年月日の元号の丸囲みは、チェック項目と和暦の印字に置き換えた。発症年月日は「令和5年3月」のように自由記述で書く。
- 「医学的管理の必要性」の下線(特に必要性の高いもの)は引けない。必要なら特記すべき事項に書く。
- 2 ページ目の上部に「主治医意見書(２ページ目)」の見出しを付けた。
