# フォーカスチャーティング(F-DAR)テンプレート

看護記録をフォーカスチャーティングの形式で書くテンプレート。患者の関心事・出来事を見出し(**F**: フォーカス)に立て、
**D**(データ)・**A**(アクション)・**R**(レスポンス)に分けて書く。

| ファイル | テンプレート | name / canonical |
|---|---|---|
| `nursing-focus-01.questionnaire.json` | フォーカスチャーティング(F-DAR) | `NURS_FOCUS_01` / `http://fhir-client.local/Questionnaire/nursing-focus-01\|1.0.0` |

レイアウト(`.tlf`)・マッピング定義は無し。テンプレート一覧のインポートから取り込む。カテゴリ **「看護記録」**
(code `ed9cf5a2-5752-4e62-85e5-cab6667aa11d`)を拡張に持たせてある(別環境へ入れるときは `questionnaire_categories` に
作った code へ差し替えるか、同じ code でカテゴリを作る)。

## 使い方: 診療記録の記載形式「テンプレート」

管理 > 診療記録タイトルで、タイトル(例:「看護記録(フォーカス)」)の記載形式を「テンプレート」、既定テンプレートを
このテンプレート、職種を看護師にすると、看護師が新しい記録を開いたときに F-DAR のフォームが出る。看護職が書いた記録なので
保存時に `category` に看護記録の印が付き、看護サマリーの「看護経過」の取込の対象になる。反映すると本文は次の形になる。

```
【フォーカス】
F(フォーカス): #1 転倒リスク状態
D(データ): 夜間トイレ歩行時にふらつきあり。睡眠薬内服後。
A(アクション): 夜間はナースコールで呼ぶよう説明。離床センサーを設置。
R(レスポンス): 「次から呼びます」と返答あり。
【フォーカス】
F(フォーカス): 疼痛
...
```

## 構成

| グループ | 項目 |
|---|---|
| フォーカス(繰り返し) | F(フォーカス)(必須) / D(データ) / A(アクション) / R(レスポンス) |

- 1 回の記録に複数のフォーカスを立てるので、F-DAR をまとめて繰り返しグループにしている(最大 10。JASPEHR の jsp-10 で上限が必須)。
- 必須は F だけ。フォーカスチャーティングでは D・A・R が 1 回の記録で揃うとは限らない(反応は後で書く、データだけ残す など)。
- F は自由記載。看護問題に限らず症状・出来事・状態の変化・治療・患者や家族の反応を立てる。看護計画の看護問題なら番号ごと書く。
- 各項目の意図は `designNote`(編集画面の「設計メモ」。回答フォームには出ない)に書いてある。

## 項目コード(item.code)を入れていない理由

F・D・A・R はいずれも自由記載で、構造化データとして集計する対象ではない。対応する確度の高い標準コードも無いので
入れていない(「回答から Observation を生成する」も無効のまま)。
