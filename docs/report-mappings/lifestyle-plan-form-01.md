# 生活習慣病 療養計画書 様式テンプレート

文書作成の「様式」(`../features/templates.md`「文書作成」)で使う、生活習慣病管理料の療養計画書。
紙面は令和 6 年度改定の別紙様式 9(初回用)・別紙様式 9 の 2(継続用)の項目立てに合わせて本アプリ用に起こしたもの(A4 縦 1 ページ)。

| ファイル | 用途 |
|---|---|
| `lifestyle-plan-initial-form-01.json` | 初回用のエクスポートファイル(項目 93 件) |
| `lifestyle-plan-continued-form-01.json` | 継続用のエクスポートファイル(項目 97 件) |
| `gen_lifestyle_plan_form.py` | 上の 2 本の生成スクリプト。紙面を HTML で組み、Chrome のヘッドレスで 1240x1754px(150dpi)の PNG にする |

## 使い方

1. マスタメンテ > テンプレート > 文書テンプレートの「様式」タブ →「インポート」で 2 本の JSON を取り込む。
   カテゴリは「計画書」(code `20f88598-bea0-4280-8e85-24c639035e57`、無ければ名称)に引き当てる。
   どちらも無ければカテゴリ未設定で入るので、カテゴリ管理で作ってから編集で設定する。
2. 取り込んだ様式は無効で入るので、編集で有効にする。
3. カルテ右ペイン「文書作成」→「生活習慣病 療養計画書（初回用）」または「（継続用）」で入力し、「作成」で PDF をファイルタブに保存する。

紙面や配置を直すときは `gen_lifestyle_plan_form.py` を直して再生成する(初回用と継続用は同じ `build` から作り、差分は `continued` で分ける)。

## 初期値

| 項目 | 初期値 |
|---|---|
| 記入日 | `%today`(和暦) |
| 患者氏名 | 漢字氏名 |
| 生年月日・年齢 | `%patient.birthDate`(和暦) / `%age` |
| 医師氏名 | `%authorName` |
| 血液検査の HbA1c・血糖・総コレステロール・中性脂肪・HDL・LDL | `%labs.where(code = '<結果項目コード>').value`(それぞれ 160010010 / 160019410 / 160022410 / 160020910 / 160023410 / 160167250) |
| 採血日 | HbA1c の `.date` |

結果項目コードは同梱の結果項目マスタのもの(`gen_lifestyle_plan_form.py` の `LAB_CODES`)。施設のマスタが違えばスクリプトを直して
作り直すか、デザイナで項目の初期値を選び直す。目標値は手入力。血液検査のチェック欄(□HbA1c など)は初期値を持てないので手で付ける。

## 初回用と継続用の差

| | 初回用 | 継続用 |
|---|---|---|
| 記入日の横 | — | （　）回目 |
| ねらい | 検査結果を理解できること・… | 重点目標の達成状況を理解できること・… |
| 目標 | ①達成目標・②行動目標 | ①目標の達成状況・②達成目標・③行動目標 |
| 食事・運動 | — | 先頭に「今回は、指導の必要なし」 |
| たばこ | 「非喫煙者である」あり | 「非喫煙者である」なし |
| 署名欄の下 | — | 説明を受けて理解したことの確認(チェックすれば患者署名を省略可) |

## 紙様式との差分

- 性別「男・女」、食べ方「ゆっくり食べる」、運動処方の「ウォーキング」「30分以上」「ほぼ毎日」「息がはずむが会話が可能な強さ」、
  栄養状態「低栄養状態の恐れ・良好・肥満」の丸囲みは、チェック項目に置き換えた。
- 生年月日の元号の丸囲みは和暦の印字に置き換えた。
- 患者署名欄は手書き用の空欄のまま(入力項目なし)。
