# ベッドスケジュール・病床状況・入退院文書の作成状況

`functional.xlsx` の「ベッドスケジュール」「病床管理一覧」「入退院文書の作成状況」(`docs/functional-gap-backlog.md`
§1 #9、§2.2・§2.6)に当たる 3 画面。**状態: 実装済(2026-10-10)。**

- **［事実］** = このリポジトリ・上流の実装で確認した内容
- **［設計］** = 本ドキュメントの決めごと

## 1. 方針

- **［設計］** 3 画面とも専用のデータを持たない。入院(`Encounter`)と病棟・病室・ベッド(`Location`)、文書
  (`Composition` / `QuestionnaireResponse`)を読んで画面側で組み立てる。持つのは入退院文書の対象と期限
  (施設設定 `admission_documents`)だけ。
- **［事実］** 入院は `location` に床の履歴を持つ(先頭が今の床、後ろほど古い。移動した床は `period.start` に
  移動日、それまでの床は `status=completed` + `period.end` に同じ日。`fhir/encounterHelpers.ts` の
  `buildBedTransferEncounter`)。退院は `status=finished` + `period.end`。入院予定は `status=planned` で、
  `location` に病棟(必須)・病室・ベッド(任意)を `physicalType` 付きで並べる。退院予定・転科転棟予定はローカル拡張。
- **［設計］** 床の履歴を「区間」(`BedSegment`: 床・入った日・出た日・退院で終わったか・入院の最初の床か)に
  起こし、ガントの帯と病床の集計の両方をこれで作る(`fhir/bedScheduleHelpers.ts`)。
- **［事実］** 期間に一日でも在院した入院は `Encounter?date=ge<from>&date=le<to>` の AND で引ける(入院患者一覧の
  1 日の引き方を期間に広げたもの。`api/queries/bedManagement.ts` の `useEncountersInRange`)。

## 2. ベッドスケジュール(`/bed-schedule`)

- **［設計］** 行は病棟の病室 → ベッド(`useWardGrid`)、列は日付(2 週間・4 週間、開始日の既定は今日の 3 日前)。
  ベッドの行に日数ぶんの 1 セルを置き、帯を `left = 日の番号 ÷ 日数` で絶対配置する(`table-layout: fixed` で列は等分)。
- **［設計］** 帯の種類:
  - 実績: 区間の入った日から、移動で終わった区間は移動の前日まで、退院で終わった区間は退院日まで
  - 続いている入院: 今日までが実績、明日から先は「今後」(退院予定日まで。無ければ表の右端まで開いた形)。
    退院予定日を過ぎても在院していれば今日まで。転科・転棟予定があれば予定日の前日まで
  - 予定: 入院予定(ベッドまで決まっているもの、予定日の 1 日)と転科・転棟予定の移動先(ベッドまで決まっているもの、
    予定日から退院予定または右端まで)。点線の枠
- **［設計］** 同じベッドで帯が重なれば段を分ける(左から貪欲に空いている段へ)。ベッドの決まっていない入院予定は
  最下段「ベッド未定」に予定日の列で並べる。
- **［設計］** 帯を押すとカルテ。仮決定と確定の色分けは「予定」と「実績」の区別で代える(入院予定に仮・確定の区別が
  データとして無いため)。

## 3. 病床状況(`/bed-status`)

- **［設計］** 病棟ごとの集計は `wardBedStats`。ベッドの所属は `useBedWardIndex`(ベッド → 病棟・病室・病室の区分・
  使えるか)で、ベッドか病室の `status` が `active` でなければ「休止」として使えるベッドから外す
  (使用禁止床の専用の持ち方は無い。病室・ベッドを無効にする運用で代える)。
- **［設計］** 数え方:
  - 在院 = その日の 24 時にいる患者(区間が `start <= 日 < until`)。稼働率 = 在院 ÷ 使えるベッド
  - 空床 = 使えるベッドのうち在院の無い床、病室の区分別
  - 入院・退院・転入・転出 = その日に始まった最初の区間 / 退院で終わった区間 / 別の病棟から移ってきた区間 /
    別の病棟へ移った区間(同じ病棟の中の転床は数えない)
  - 翌日の入院予定 = 予定日が翌日で予定先がその病棟の入院予定。翌日の退院予定 = 退院予定日が翌日でいまその病棟にいる入院
  - 在院患者延日数 = 期間の夜の数(入院日を数え退院日は数えない)。病床利用率 = 延日数 ÷ (使えるベッド × 日数)、
    平均在院日数 = 延日数 ÷ ((新入棟 + 新退棟) ÷ 2)。病棟の新入棟・新退棟は転出入を含み、合計の行は入院と退院だけ
- **［設計］** 届出の様式(短期滞在手術等の患者の除外など)には合わせない簡易計算。必要になったらデータ抽出の
  「入院・外来」タブの内訳で正式な集計を組む。

## 4. 入退院文書の作成状況(`/admission-documents`)

- **［設計］** 対象は入院中の入院と、指定日(既定は 30 日前)以降に退院した入院。判定は
  `fhir/admissionDocumentHelpers.ts`:

  | 文書 | 何で数えるか | 期限 |
  |---|---|---|
  | 入院診療計画書 | 施設設定のテンプレート(url、版を問わない)への回答。completed / amended → 作成済、in-progress → 作成中 | 入院日 + `admission_plan_days`(既定 7) |
  | 退院時サマリー | type LOINC 18842-5 の Composition(`encounter`)。preliminary → 作成中、それ以外 → 確定 | 退院日 + `document_reminder.discharge_summary_days` |
  | 看護サマリー | 区分「退院」の看護サマリー(`encounter`)。作成中 / 承認待ち / 承認済(承認待ちも作成済) | 退院日 + `nursing_summary_days`(既定 7) |
  | 栄養スクリーニング・栄養管理計画書 | `docs/nutrition-care-plan-design.md` | 入院日 + `nutrition_screening_days`(既定 3)・`nutrition_plan_days`(既定 7) |
  | 褥瘡リスク評価・褥瘡対策計画書 | `docs/pressure-ulcer-plan-design.md` | 入院日 + `pressure_ulcer_risk_days`(既定 1)・`pressure_ulcer_plan_days`(既定 7) |

- **［設計］** 退院系の文書は退院するまで期限が決まらないので「退院後」と出す(書き始めていれば状態を出す)。
  期限を過ぎて作成済でなければ期限超過。
- **［設計］** 入院診療計画書の回答は、`encounter` を持てばそれで、持たなければ記入日が入院日の 7 日前〜退院日
  (入院中は今日)に入るもので入院に当てる。一覧から書き始めた回答は `encounter` を持つ(右ペインの
  `admission-plan-create`、カルテの `?open=admission-plan:<入院>`)。
- **［事実］** 上流の canonical 検索は、版を省いた url では版付きの値に当たらない(`server-improvement-backlog.md` C-10)。
  テンプレートの版を `Questionnaire?url=` で引き、版ごとの canonical を並べて引いている。
- **［設計］** セルからの入口: テンプレートで書く文書は、未作成なら登録を始め、作成済・作成中はその回答を右ペインで開く
  (`?open=questionnaire-response:<回答>`。入院に結び付いた回答はカルテの時系列に出ないため)。
  退院時サマリーは既存の `?open=discharge-summary:<入院>`、看護サマリーは作成済なら `?open=nursing-summary:<id>`、
  未作成なら `?open=nursing-summary-create:<入院>`(入院が退院済なら区分「退院」で始まる)。
- **［設計］** 入院診療計画書のテンプレートの既定は空(どのテンプレートを使うかは施設が決める)。空なら列を出さない。

## 5. 残っていること

- 感染症の印(ベッドスケジュールの帯)、男女の色分け、病室タイプ・差額での空床検索
- 入院予定の仮決定・確定の区別と、帯のドラッグでの予定の変更(いまは入院予定・転科転棟予定のモーダルで変える)
- 退院療養計画書など、入院診療計画書以外のテンプレート文書を対象に足す(施設設定を「文書の一覧」に広げる)
- 入院実施の transaction で入院診療計画書の下書きを作る自動発生
- 届出の様式に合わせた病床利用率・平均在院日数(除外する患者の扱い)
