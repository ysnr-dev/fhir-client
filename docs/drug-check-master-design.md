# 薬剤チェックの施設マスタ

相互作用(併用禁忌・併用注意)と、用量・患者条件(年齢・腎機能・体重)のチェックを、施設が登録するマスタで行う。
処方・注射のフォームの薬剤行に、アレルギー・重複投与(`docs/order-common-backlog.md` §3)と同じ並びで警告を出す。
**登録は止めない**(判断は医師のもの)。

公開データでそのまま使えるものが無いため施設マスタにした(2026-10-03)。電子添文 XML の相互作用は相手薬が文章で、
用量・腎機能・年齢は文章か書籍しか無い。網羅したければ商用の医薬品データベースを契約して、このマスタに取り込む形になる。

## 1. 持つもの

薬は **YJ コードの先頭 4〜7 桁**で指す。7 桁 = 成分(薬効分類 4 桁 + 成分 3 桁)、4 桁 = 薬効分類。
薬剤行の成分キー(`medicationSafetyHelpers.ingredientKey`、YJ 上 7 桁)の前方一致で当てる。
YJ コードを持たない薬(HOT コードマスタに無い統一名収載品。例: ワルファリンカリウム錠)は薬価基準コードの
上 7 桁を使う(YJ と上 9 桁が一致する)。保存済みのオーダー・持参薬は薬価基準コードを持たないので、
医薬品マスタをレセプト電算コードで引き直して補う(`fetchYakkaCodes`)。
4 桁で書けば「その他の解熱鎮痛消炎剤(1149)すべて」のように群でまとめて書ける。

- `master_drug_interactions` — `code_a`/`name_a`・`code_b`/`name_b`・`severity`(contraindicated = 併用禁忌 / caution = 併用注意)・`note`(機序・症状・対処)。
  同じ組み合わせは向きを問わず 1 件(A-B と B-A を両方持たない)。
- `master_drug_dose_rules` — `code`/`name`・`dosage_form`(1 内用 / 4 注射 / 6 外用、空ならすべて)・条件・上限・`severity`(禁忌 / 注意)・`message`。
  - 条件: 年齢 `age_from` 歳以上 `age_to` 歳未満、腎機能 `renal_index`(egfr / ccr)が `renal_below` 未満。どちらも任意で、書いたものがすべて当てはまったとき規則が効く。
  - 上限: `max_single_dose`(1 回量)・`max_daily_dose`(1 日量)・`dose_unit`・`per_kg`(体重 1 kg あたり)。
  - 上限があれば用量を比べて超えたときだけ出す。上限が無ければ条件が当てはまった時点で `message` を出す(この場合 `message` 必須)。
  - 条件も上限も無い規則は登録できない(薬を選ぶたびに出るだけになるため)。

医薬品マスタとは FK で結ばない(取込で id が変わる。フォーミュラリと同じ理由)。

## 2. 照合(`fhir/drugCheckHelpers.ts`)

- **相互作用**: 相手はフォームの別の行と、投与中の処方・持参薬(`useActiveMedications` + 未判断の持参薬。重複投与と同じ範囲)。
  `[RP2]`・`投与中`・`持参薬` のどこにあるかを添える。併用禁忌は赤。
- **年齢**: 生年月日から。
- **腎機能**: プロファイルの身体区画と同じ値(最新のクレアチニンから eGFR は日本腎臓学会の式、CCr は Cockcroft-Gault)。
  値が無いときは「eGFR が無いため確認できません」を弱く出す(規則があることは伝える)。
- **用量**: 行の量を規則の単位に換算して比べる(`doseConversionHelpers.convertDose`。投与量換算マスタの係数を使う)。
  換算行が無ければ「換算できず確認できません」を出す。体重あたりは最新の体重 × 上限で、体重が無ければその旨を出す。
  - 処方: 日数を持つ内服は用量 = 1 日量。1 回量は不均等なら最大の回、そうでなければ 1 日量 ÷ 用法コード 4 桁目の回数。
    頓用は用量 = 1 回量(1 日量は比べない)。外用は量の意味が決まっていないので比べない。
  - 注射: 用量 = 1 回量、1 日量 = 1 回量 × 施用時刻の数(未入力は 1 回)。
- 上限超過・禁忌は赤、注意・確認できない旨は通常の警告色。

## 3. 画面

`/drug-checks`(マスタメンテ > 医薬品 > 薬剤チェック)。タブで相互作用 / 用量・患者条件を切り替え、行の「編集」でモーダル。
医薬品はまず「成分 / 薬効分類」を選ぶ。成分は「医薬品から選ぶ」(医薬品検索から YJ 上 7 桁と一般名。名称は手で直せる)、
薬効分類は薬効分類の一覧から直接選ぶ(番号 4 桁の直打ちも可)。

オーダー画面は両マスタを全件読んで手元で照合する(5 分キャッシュ)。

## 4. API

- `GET /master/drug_interactions?q=` / `GET /master/drug_dose_rules?q=` — 全件(ページングなし)。`q` は名称・コード・文言の部分一致
- `POST/PATCH/DELETE /master/drug_interactions/:id`、`/master/drug_dose_rules/:id`

## 5. 限界・残り

- 同じ成分を複数行に分けたときの 1 日量は行ごとに比べる(合算しない)。重複投与の警告は別に出る。
- 投与中の**注射**は相互作用の相手に入らない(`useActiveMedications` が処方だけを返すため)。
- YJ コードも薬価基準コードも持たない薬剤(医薬品マスタに無いもの)は照合されない。
- 「CYP3A4 を強く阻害する薬剤」のような薬効分類に沿わない群は、成分ごとに行を分けて登録する(群のマスタは持たない)。
- レジメン編集・適用の画面には未適用(化学療法は体表面積あたりの投与量で、別の投与前チェックがある)。
