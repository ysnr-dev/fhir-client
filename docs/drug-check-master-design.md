# 薬剤チェックの施設マスタ

相互作用(併用禁忌・併用注意)、用量・患者条件(年齢・腎機能・体重)・投与日数、病名の禁忌・注意のチェックを、施設が登録するマスタで行う。
あわせて、薬剤付加情報(`docs/lot-number-design.md`)と施設設定による採用区分・処方できる診療科・粉砕分割・剤形と用法・
処方区分ごとの日数の照合も同じ並びで出す(§2.2)。
処方・注射のフォームの薬剤行に、アレルギー・重複投与(`docs/order-common-backlog.md` §3)と同じ並びで警告を出す。
**登録は止めない**(判断は医師のもの)。

公開データでそのまま使えるものが無いため施設マスタにした(2026-10-03)。電子添文 XML の相互作用は相手薬が文章で、
用量・腎機能・年齢は文章か書籍しか無い。網羅したければ商用の医薬品データベースを契約して、このマスタに取り込む形になる。

## 1. 持つもの

薬は **YJ コードの先頭 4〜7 桁**で指す。7 桁 = 成分(薬効分類 4 桁 + 成分 3 桁)、4 桁 = 薬効分類。
薬剤行の成分キー(`medicationSafetyHelpers.ingredientKey`、YJ 上 7 桁)の前方一致で当てる。
YJ コードを持たない薬(HOT コードマスタに無い統一名収載品。例: ワルファリンカリウム錠)は薬価基準コードの
上 7 桁を使う(YJ と上 9 桁が一致する)。保存済みのオーダー・持参薬は薬価基準コードを持たないので、
医薬品マスタをレセプト電算コードで引き直して補う(`fetchYakkaCodes`)。
4 桁で書けば「その他の解熱鎮痛消炎剤(1149)すべて」のように群でまとめて書ける。

- `master_drug_interactions` — `code_a`/`name_a`・`code_b`/`name_b`・`severity`(contraindicated = 併用禁忌 / caution = 併用注意)・`note`(機序・症状・対処)。
  同じ組み合わせは向きを問わず 1 件(A-B と B-A を両方持たない)。
- `master_drug_dose_rules` — `code`/`name`・`dosage_form`(1 内用 / 4 注射 / 6 外用、空ならすべて)・条件・上限・`severity`(禁忌 / 注意)・`message`。
  - 条件: 年齢 `age_from` 歳以上 `age_to` 歳未満、腎機能 `renal_index`(egfr / ccr)が `renal_below` 未満。どちらも任意で、書いたものがすべて当てはまったとき規則が効く。
  - 上限: `max_single_dose`(1 回量)・`max_daily_dose`(1 日量)・`dose_unit`・`per_kg`(体重 1 kg あたり)。
  - 上限があれば用量を比べて超えたときだけ出す。上限が無ければ条件が当てはまった時点で `message` を出す(この場合 `message` 必須)。
  - 条件も上限も無い規則は登録できない(薬を選ぶたびに出るだけになるため)。
  - 累積の上限: `max_cumulative_dose`(生涯の累積投与量)・`cumulative_per_bsa`(体表面積 1 m² あたり)。単位は `dose_unit`。
    比べるのは化学療法の適用・次クール登録だけ(`docs/chemo-regimen-design.md` §8.23)。処方・注射のフォームは
    累積の上限だけの規則を無視する。`per_kg` は 1 回量・1 日量にだけ効く。
  - 投与日数の上限: `max_days`(新薬・麻薬・向精神薬の 14 日 / 30 日 / 90 日など)。処方の日数を持つ内服の RP の日数と比べる。
    上限が日数だけの規則は文言が無くてもよい。
- `master_drug_disease_rules` — `code`/`name`(薬)・`disease_code`/`disease_name`(病名)・`severity`(禁忌 / 注意)・`note`(理由・対処)。
  病名は ICD-10 の先頭 3〜5 文字(点なし。`K25` で胃潰瘍すべて、`J459` で細分類)。同じ薬と病名は 1 件。
  適応症の確認は商用の医薬品データベースが無いと網羅できないので持たない。

医薬品マスタとは FK で結ばない(取込で id が変わる。フォーミュラリと同じ理由)。

## 2. 照合(`fhir/drugCheckHelpers.ts`)

- **相互作用**: 相手はフォームの別の行と、投与中の処方・持参薬(`useActiveMedications` + 未判断の持参薬。重複投与と同じ範囲)。
  `[RP2]`・`投与中`・`持参薬` のどこにあるかを添える。併用禁忌は赤。
- **病名**: 患者の活動中の病名(看護問題を除く。上流の `clinical-status=active`、欠けた結果は使わない)の ICD-10 を
  規則の病名で前方一致。疑い病名も当てる。禁忌は赤、注意は通常の警告色。
- **投与日数**: 規則の `max_days` と RP の日数。超えたら赤(「確認を要する」)。
- **年齢**: 生年月日から。
- **腎機能**: プロファイルの身体区画と同じ値(最新のクレアチニンから eGFR は日本腎臓学会の式、CCr は Cockcroft-Gault)。
  値が無いときは「eGFR が無いため確認できません」を弱く出す(規則があることは伝える)。
- **用量**: 行の量を規則の単位に換算して比べる(`doseConversionHelpers.convertDose`。投与量換算マスタの係数を使う)。
  換算行が無ければ「換算できず確認できません」を出す。体重あたりは最新の体重 × 上限で、体重が無ければその旨を出す。
  - 処方: 日数を持つ内服は用量欄の入力区分(1 回量 / 1 日量)から、もう一方を用法コード 4 桁目の回数で出して両方を比べる
    (`prescriptionLineDose`)。不均等なら 1 回量は最大の回。頓用は用量 = 1 回量(1 日量は比べない)。
    外用は量の意味が決まっていないので比べない。
  - 注射: 用量 = 1 回量、1 日量 = 1 回量 × 施用時刻の数(未入力は 1 回)。
- 上限超過・禁忌は赤、注意・確認できない旨は通常の警告色。

### 2.2 薬剤付加情報・施設設定との照合(`fhir/prescriptionCheckHelpers.ts`)

| 種別(警告) | 判定 | 重さ |
|---|---|---|
| 採用区分 `adoption` | 院内で調剤するオーダー(入院・外来の院内処方・注射)に採用外・院外専用の薬。仮採用は場所を問わず表示のみ。施設設定「採用区分が未設定の薬を採用外とする」で、区分を決めていない薬も採用外として扱う(採用薬だけを登録する運用) | 確認 / 表示のみ |
| 処方できる診療科 `restricted-department` | 薬剤付加情報の診療科があり、依頼科(処方監査では処方の依頼科)がそれに無い | 確認 |
| 粉砕・分割 `crush-split` | RP の調剤指示に粉砕があり粉砕不可の薬、1 回量(不均等なら各回)に端数があり分割不可の薬 | 確認 |
| 剤形と用法 `usage-form` | 医薬品マスタの剤形と用法の基本区分の食い違い(内用薬は内服・注入、注射薬は注射・注入、外用薬は外用)。保存済みのオーダーから起こした行は剤形を持たないので見ない | 表示のみ |
| 投与日数の上限 `days-limit` | 施設設定「処方のチェック」の処方区分ごとの上限(0 は上限なし)を RP の日数が超える。RP の最初の薬の行に出す | 確認 |

一般名処方の行は医薬品コードが一般名処方コードなので付加情報が当たらない(院外処方にしか無いので採用区分は問題にならない)。

## 3. 画面

`/drug-checks`(マスタメンテ > 医薬品 > 薬剤チェック)。タブで相互作用 / 用量・患者条件 / 病名を切り替え、行の「編集」でモーダル。
病名は「病名選択」で病名マスタから選ぶと ICD-10 が細分類まで入る(分類でまとめるときは先頭 3 文字に縮める)。
医薬品はまず「成分 / 薬効分類」を選ぶ。成分は「医薬品選択」(医薬品検索から YJ 上 7 桁と一般名。名称は手で直せる)、
薬効分類は薬効分類の一覧から直接選ぶ(番号 4 桁の直打ちも可)。

オーダー画面は両マスタを全件読んで手元で照合する(5 分キャッシュ)。結果は共通の警告(`advisory-design.md`)に写し、
併用禁忌・上限超過は「確認を要する」(登録時に理由が必須)、併用注意・確認できない旨は「表示のみ」になる。

## 4. API

- `GET /master/drug_interactions?q=` / `GET /master/drug_dose_rules?q=` / `GET /master/drug_disease_rules?q=` — 全件(ページングなし)。`q` は名称・コード・文言の部分一致
- `POST/PATCH/DELETE /master/drug_interactions/:id`、`/master/drug_dose_rules/:id`、`/master/drug_disease_rules/:id`

## 5. 限界・残り

- 同じ成分を複数行に分けたときの 1 日量は行ごとに比べる(合算しない)。重複投与の警告は別に出る。
- 投与中の**注射**は相互作用の相手に入らない(`useActiveMedications` が処方だけを返すため)。
- YJ コードも薬価基準コードも持たない薬剤(医薬品マスタに無いもの)は照合されない。
- 「CYP3A4 を強く阻害する薬剤」のような薬効分類に沿わない群は、成分ごとに行を分けて登録する(群のマスタは持たない)。
- レジメン編集・適用の画面には 1 回量・1 日量・相互作用は未適用(化学療法は体表面積あたりの投与量で、別の投与前チェックがある)。
  累積の上限だけはレジメンの適用で比べる。
