# 外来患者一覧と待合表示板

## 外来患者一覧(`/outpatients`)

メニュー「患者一覧 > 外来患者一覧」。1 行が予約(Appointment)1 件で、診察日(既定は今日)の予約を予約時間の順に並べます。
検査予約(オーダーにぶら下がる予約)は部門のワークリストが追うので出しません。絞り込み(診療科・担当医・診察室・状態)と日付は
URL に持ち、カルテから「戻る」で同じ一覧に戻れます。「自動更新」(端末ごと、既定は切)で 1 分ごとに読み直します。

- **列**: 予約時間・受付時間・受付番号・待ち時間(受付済で診察前の行だけ、今日の一覧だけ)・患者番号・患者氏名(左 6 列は固定)、
  生年月日・性別、初再診、予約枠、診療科、担当医、診察室、状態、当日オーダー、問診、操作。
- **状態**: 予約済 → 受付済 → 診察中 → (一時終了 →) 診療済。「診察中」「一時終了」は予約の status に無いので、その予約の外来 Encounter
  (`in-progress` / `onleave`)から出します(`fhir/outpatientEncounterHelpers.ts`)。上の帯に状態ごとの件数を出します。
- **受付**: 予約の行の「受付」で `checked-in` にし、受付時刻(拡張 `appointment-checked-in-at`)と**受付番号**を書きます。
  「当日受付」「新患登録」は予約の無い来院を、診療科・担当医・診察室・初再診を添えて受付済の予約として作ります。受付取消で
  受付時刻と受付番号は外れます。
- **受付番号**: 受付のたびに backend が当日の連番を払い出し(`POST /waiting_board/reception_numbers`)、`Appointment.identifier`
  (system `http://fhir-client.local/identifier/reception-number`)に持ちます。待合表示板の呼出番号で、患者には受付でこの番号を
  伝えます。レセコン連携で取り込んだ受付はレセコンの受付 ID をそのまま使います。払い出したあと書き込みに失敗した番号は欠番です。
- **診察開始 / 診察終了**: 「診察開始」で外来 Encounter を建ててカルテを開きます(待合表示板ではこれが「お呼び出し」です)。
  「診察終了」で Encounter を `finished`、予約を `fulfilled` にします(同じ transaction)。カルテ見出しの同じボタンと
  一時終了・診察再開は `features/karte.md` を参照。
- **行メニュー**: 編集(診療科・担当医・診察室)、問診 QR、受付取消、医事会計へ会計送信(連携が有効なとき)、予約取消。

設計は `docs/waiting-board-design.md`(受付番号)、`docs/web-intake-design.md`(問診)、`docs/receipt-billing-design.md`(会計送信)。

## 待合表示板(`/board/<token>`)

ロビーのモニターに、診察室ごとの「お呼び出し中の受付番号・お待ちの方の人数・検査などで離席中の人数・本日の平均待ち時間」を
ログイン無しで出します。患者番号や氏名は出しません。30 秒ごとに読み直し、読み直せないときは直前の表示を残して
「更新できていません」を添えます。

- **区画**: 診察室(場所の種別「外来(診察室)」)ごとに 1 枚。診察室が未割当の受付は診療科でまとめた区画に出します。
- **お呼び出し中**: 「診察開始」した受付の番号(診察中)。待ち = 受付済で診察前、離席中 = 一時終了。
  平均待ち時間はその日の受付→診察開始の実測の平均(実測が無ければ出しません)。
- **リンクの発行**: 「管理 > 施設設定 > 待合表示板」で名前(置き場所)と出す診察室(未選択なら全部)を入れて「発行」すると、
  URL と QR が 1 度だけ出ます(トークンは保存しないので、また要るときは発行し直します)。発行済みの表のゴミ箱で取消すると、
  その URL は「この表示板のリンクは無効です。」になります。
- 上流は検索のたびに監査ログを書くので、表示板を置く端末は必要な台数に絞ります。

設計は `docs/waiting-board-design.md`。待ち時間の集計はデータ抽出「入院・外来」の外来の列「待ち時間(分)」
(`features/data-analysis.md`)。
