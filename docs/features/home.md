# ホーム・掲示板

## ホーム(トップページ)

`/` はログインした人の「今日の仕事」を 1 画面に集めるホームです(ヘッダーのタイトルで戻れます。
患者検索は従来どおり `/patients`)。何を出すかは職種(所属ロールの `PractitionerRole.code`)で決め、
判定は `frontend/src/fhir/homeSections.ts` の `homeProfileOf` に集めてあります。

| 職種 | 通知 | 本日の外来 | 担当入院患者 | 部門ワークリスト件数 |
|---|---|---|---|---|
| administrator(医療従事者に紐付かない) | – | – | – | –(掲示板だけ) |
| 医師・歯科医師 | 自分宛て | 自分が担当医の予約 | 主治医(participant ATND) | – |
| 看護師・保健師・助産師 | 自分宛て | – | 担当看護師・その日の受け持ち(業務分担) + 未指示受け件数 | – |
| 薬剤師 | 自分宛て | – | – | 処方 / 注射 / 持参薬鑑別 / 服薬指導 |
| 診療放射線技師 | 自分宛て | – | – | 放射線検査 / 放射線治療 |
| 臨床検査技師・衛生検査技師 | 自分宛て | – | – | 検体検査 / 生理検査 / 病理検査 / 輸血 |
| 理学・作業療法士、言語聴覚士 | 自分宛て | – | – | リハビリ |
| 管理栄養士 | 自分宛て | – | – | 栄養指導 |
| 事務職員・その他・職種未登録 | 自分宛て | 全体 | – | – |

- 所属科は見出しにチップで出すだけで、絞り込みには使いません(医師の外来・入院は医師 id で絞ります。
  科で絞ると他科で診た予約が落ちるため)。所属科が複数ある人は既定科を先頭に「(既定)」を添えて並べます。
- 職種→部門の対応は `homeSections.ts` の `HOME_WORKLISTS` 1 か所です。部門を足すときはここに 1 行と、
  `components/HomeWorklistCard.tsx` にその部門の hook を呼ぶカードを 1 つ足します。
- 各カードは対応する一覧ページと**同じ hook**で読みます(通知は `useNotifications`、外来は
  `useOutpatientList`、入院は `useInpatientEncounters` + `useBedWardIndex`、部門は `useLabWorklist` など)。
  一覧ページと同じキャッシュに乗るので、カードから一覧へ移っても読み直しは起きません。
- 部門の「未処理」は Task の状態が `completed` / `cancelled` 以外の件数です(Task がまだ無いオーダーは
  依頼済として数えます)。内訳は部門ごとの語彙(受付済 / 実施中 / 出庫済 …)でそのまま出します。
  放射線治療は日付ではなく進行中のコース、持参薬鑑別は未鑑別の依頼を数えます。
- 遷移先: 通知の行は種別ごとのカルテリンク、外来の行と入院の行はその患者のカルテ。見出しのリンクは
  外来が `/outpatients?date=<今日>&practitioner=<自分>`(医師)、入院が病棟ごとに `/inpatients?ward=<病棟>`。
  看護師の「指示受け n」はカルテの指示簿タブを開きます。
- 自動更新は既定で切ってあります(通知のベル・外来一覧と同じ理由。上流は検索のたびに監査ログを書く
  ため)。入れると外来のカードだけ 1 分ごとに読み直します。通知の件数はヘッダーのベルの設定に従います。
- 職種によらず先頭に「掲示板」のカードが出ます(下の「掲示板」)。

## 掲示板(院内のお知らせ)

患者に紐付かない施設内の連絡(計画停止・職員向けの案内など)を貼る掲示板です。上流 FHIR には
置かず backend の `bulletin_posts` に持ち、`/master/bulletin_posts` で読み書きします(ログイン認証・
CSRF はチャート定義と同じ `/master` の基底)。

- 投稿は件名・本文・掲載期間(開始日 〜 終了日、終了日なしは無期限)・「先頭に固定」を持ちます。
  投稿者は上流の `Practitioner.id` と表示名を焼き付けます(administrator は id なし・表示名「管理者」)。
- 読む・投稿するのはログインした人なら誰でも。直す・消すのは**投稿した本人か administrator** だけです
  (応答の `editable` で画面が「編集」を出し分けます。認証なしモードでは誰でも直せます)。
- ホームのカード(`/`)は**今日掲載中**のものを固定を先頭に新しい順で 5 件出し、長い本文は 3 行に畳んで
  「続き」で開きます。掲示板の画面(`/bulletin`、ヘッダーの「掲示板」)は掲載前・掲載終了も含めて
  全件を並べ、期間外には印を付けます。
- 「今日」はブラウザの日付を `date` で渡します(サーバーの時計は UTC で、朝 9 時前は前日になるため)。
  掲載開始日も画面が必ず送ります。
