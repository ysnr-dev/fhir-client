# ホーム・掲示板

## ホーム(トップページ)

`/` はログインした人の「今日の仕事」をカードで 1 画面に集めるホームです(ヘッダーのタイトルで戻れます。
患者検索は従来どおり `/patients`)。並べるカードは本人が「編集」で決めて保存でき、保存していなければ
職種(所属ロールの `PractitionerRole.code`)の既定で出ます。既定の判定は `frontend/src/fhir/homeCards.ts` の
`defaultHomeCards`、カードの種類と設定の形は同じファイルの `HOME_CARD_KINDS` に集めてあります。

### 既定のカード

| 職種 | 通知 | 本日の外来 | 担当入院患者 | 部門ワークリスト件数 |
|---|---|---|---|---|
| administrator(医療従事者に紐付かない) | – | – | – | –(掲示板だけ。編集もなし) |
| 医師・歯科医師 | 自分宛て | 自分が担当医の予約 | 主治医(participant ATND) | – |
| 看護師・保健師・助産師 | 自分宛て | – | 担当看護師・その日の受け持ち(業務分担) + 未指示受け件数 | – |
| 薬剤師 | 自分宛て | – | – | 処方 / 注射 / 持参薬鑑別 / 服薬指導 / 特定抗菌薬の届出 |
| 診療放射線技師 | 自分宛て | – | – | 放射線検査 / 放射線治療 |
| 臨床検査技師・衛生検査技師 | 自分宛て | – | – | 検体検査 / 生理検査 / 病理検査 / 輸血 |
| 理学・作業療法士、言語聴覚士 | 自分宛て | – | – | リハビリ |
| 管理栄養士 | 自分宛て | – | – | 栄養指導 |
| 事務職員・その他・職種未登録 | 自分宛て | 全体 | – | – |

- 所属科は見出しにチップで出すだけで、絞り込みには使いません(医師の外来・入院は医師 id で絞ります。
  科で絞ると他科で診た予約が落ちるため)。所属科が複数ある人は既定科を先頭に「(既定)」を添えて並べます。
- 職種によらず先頭に「掲示板」のカードが出ます(下の「掲示板」)。

### ホームの編集

見出しの「編集」でモーダルを開き、カードの並べ替え(↑↓)・削除・追加・カードごとの設定を変えて「保存」します。
「既定に戻す」で保存した設定を消し、職種の既定に戻ります。administrator は医療従事者に紐付かないので編集できません。

- 保存先は backend の `home_layouts`(医療従事者ごとに 1 行、`/master/home_layout` の GET / PUT / DELETE)。
  ログイン中は backend が本人に固定し、他人の設定は読めません。保存していない人には `definition: null` が返り、
  画面が既定を使います。端末をまたいで同じホームになります。
- backend はカードの形(`id` / `kind` / `settings`、30 枚まで、`id` 重複なし)だけを守り、種類の一覧は画面の
  registry が正典です。画面は知らない種類のカードを落とし、設定の欠けは既定で埋めます(`normalizeHomeCards`)。
- 同じ種類を複数置けるのは設定で区別できるもの(部門ワークリスト・病棟や科を選ぶカード・ダッシュボード・
  患者フォルダ)だけです。病棟・科・チーム・ダッシュボード・フォルダを選ぶカードは、選択肢が空のままだと
  保存できません。

### カードの種類

| 種類 | 設定 | 読むもの(一覧ページと同じ hook) | 遷移先 |
|---|---|---|---|
| 掲示板 | – | `useBulletinPosts`(今日掲載中、固定を先頭に 5 件) | `/bulletin` |
| 未対応の通知 | – | `useNotificationRows`(自分宛て) | `/notifications` |
| ショートカット | 画面(複数) | – | 選んだ画面 |
| 本日の外来 | 自分の予約 / 全体 | `useOutpatientList` | `/outpatients?date=<今日>&practitioner=<自分>` |
| 担当入院患者 | 主治医 / 担当看護師 | `useInpatientEncounters` + `useBedWardIndex`(看護師は業務分担と未指示受け件数も) | 病棟ごとに `/inpatients?ward=<病棟>` |
| 他科依頼 | 依頼先の科 | `useConsultWorklist("open", 科)` | `/consult-worklist` |
| カウンターサイン待ち | – | 通知と同じ検索結果をカルテ承認・オーダー承認で絞る | `/countersigns` |
| 期限のある書類 | – | 通知と同じ検索結果を文書作成で絞り、期限超過の件数を添える | `/admission-documents` |
| 看護指示 | 病棟 | `useNursingWorklist`。未処理は有効な指示のうち指示受け待ち | `/nursing-worklist?ward=` |
| 看護サマリー承認待ち | 病棟 | `useWardNursingSummaries`(直近 30 日)。承認者なしの確定済みと、自分が承認できる数 | `/nursing-summary-approvals?ward=` |
| 部門ワークリスト | 部門(16 種) | 部門ごとの一覧の hook(`HOME_WORKLISTS` と `components/homeCards/HomeWorklistCard.tsx`) | 部門の一覧 |
| 化学療法室 | – | `useChemoRoomList`(注射 Task の状態) | `/chemo-room-worklist` |
| チーム依頼 | チーム | `useTeamRequestWorklist("open", チーム)` | `/team-worklist` |
| 救急 | – | `useEmergencyList`。滞在中(来院〜診療中)の患者と本日来院の件数 | `/emergency` |
| 病棟の状況 | 病棟(空は全病棟) | 病床状況と同じ `wardBedStats` を今日 1 日ぶんで。空床・本日入退院・翌日の予定 | `/bed-status` |
| ダッシュボード | ダッシュボード | `useDashboards` + `useDashboardRun`。横 2 列・縦 2 段。開いただけでは実行せず「実行」で走らせる | `/dashboards?id=` |
| 患者フォルダ | フォルダ | `usePatientFolderMembers`(操作なしの表) | `/patient-folders?folder=` |

- 部門ワークリストの職種→部門の対応は `fhir/homeSections.ts` の `HOME_WORKLISTS` 1 か所です。部門を足すときは
  ここに 1 行と、`components/homeCards/HomeWorklistCard.tsx` にその部門の hook を呼ぶカードを 1 つ足します。
  カードの種類を足すときは `fhir/homeCards.ts` の `HOME_CARD_KINDS` に 1 要素足し、型エラーになる
  `components/homeCards/index.tsx` の対応表を埋めます。
- 部門の「未処理」は Task の状態が `completed` / `cancelled` 以外の件数です(Task がまだ無いオーダーは
  依頼済として数えます)。内訳は部門ごとの語彙(受付済 / 実施中 / 出庫済 …)でそのまま出します。
  放射線治療は日付ではなく進行中のコース、持参薬鑑別は未鑑別の依頼、手術は当日の件数に日程未定を添えます。
- 各カードは対応する一覧ページと**同じ hook**で読むので、同じキャッシュに乗り、カードから一覧へ移っても
  読み直しは起きません。通知と承認待ち・書類のカードは 1 回の Task 検索を共有します。
- 遷移先: 通知の行は種別ごとのカルテリンク、外来・入院・救急・フォルダの行はその患者のカルテ。
  看護師の「指示受け n」はカルテの指示簿タブを開きます。
- 自動更新は既定で切ってあります(通知のベル・外来一覧と同じ理由。上流は検索のたびに監査ログを書く
  ため)。入れると外来と救急のカードだけ 1 分ごとに読み直します。通知の件数はヘッダーのベルの設定に従います。
- ショートカットの候補はヘッダーのメニューと同じ登録表(`frontend/src/appMenu.ts`。「管理」を除く)です。
  メニューに画面を足すとここにも載ります。

## 掲示板(院内のお知らせ)

患者に紐付かない施設内の連絡(計画停止・職員向けの案内など)を貼る掲示板です。上流 FHIR には
置かず backend の `bulletin_posts` に持ち、`/master/bulletin_posts` で読み書きします(ログイン認証・
CSRF はチャート定義と同じ `/master` の基底)。

- 投稿は件名・本文・掲載期間(開始日 〜 終了日、終了日なしは無期限)・「先頭に固定」を持ちます。
  投稿者は上流の `Practitioner.id` と表示名を焼き付けます(administrator は id なし・表示名「管理者」)。
- 読む・投稿するのはログインした人なら誰でも。直す・消すのは**投稿した本人か administrator** だけです
  (応答の `editable` で画面が「編集」を出し分けます。認証なしモードでは誰でも直せます)。
- ホームのカード(`/`)は**今日掲載中**のものを固定を先頭に新しい順で 5 件出し、長い本文は 3 行に畳んで
  「続き」で開きます。掲示板の画面(`/bulletin`、ヘッダーの「掲示板」)は掲載前・掲載終了も含めて
  全件を並べ、期間外には印を付けます。
- 「今日」はブラウザの日付を `date` で渡します(サーバーの時計は UTC で、朝 9 時前は前日になるため)。
  掲載開始日も画面が必ず送ります。
