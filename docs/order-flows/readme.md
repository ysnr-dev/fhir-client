# オーダーの業務フロー

オーダー種別ごとの運用フロー(アクティビティ図)と開発者向けシーケンス図です。医療機関の運用を検討する人は各文書の「運用フロー」、院内の開発者は「開発者向け」を読みます。

| 文書 | 内容 |
| --- | --- |
| [prescription.md](prescription.md) | 処方オーダー(登録から調剤・与薬まで) |
| [injection.md](injection.md) | 注射オーダー(登録から払出・実施まで) |
| [chemotherapy.md](chemotherapy.md) | 化学療法(レジメンの適用からクール登録・投与・終了まで) |
| [lab.md](lab.md) | 検体検査オーダー(登録から採取・到着・結果報告・結果確認まで) |
| [transfusion.md](transfusion.md) | 輸血オーダー(登録から出庫・投与・副作用の記録まで、自己血の採血) |
| [surgery.md](surgery.md) | 手術オーダー(申込から日程確定・術前診察・入室・実施記録・症例登録まで) |
| [micro.md](micro.md) | 細菌検査オーダー(登録からラベル発行・採取・到着・中間報告・最終報告・結果確認まで) |
| [patho.md](patho.md) | 病理検査オーダー(登録から採取・ラベル発行・病理受付・レポート・結果確認・患者説明まで) |
| [rad.md](rad.md) | 放射線検査オーダー(登録から予約・受付・実施・読影・結果確認まで) |
| [physio-endoscopy-treatment.md](physio-endoscopy-treatment.md) | 生理検査・内視鏡・処置オーダー(放射線検査との違い、登録から予約・受付・実施・所見レポートまで) |
| [consult-team.md](consult-team.md) | 他科依頼・チーム依頼(登録から受付・回答、回診記録・終了まで、チームあての通知) |
| [radiotherapy.md](radiotherapy.md) | 放射線治療(依頼から治療処方・受付・照射予定・照射・週次レビュー・終了サマリーまで) |
| [rehab.md](rehab.md) | リハビリオーダー(登録から受付・次回予約・日々の実施・終了・退院での打ち切りまで) |
