# 重症度、医療・看護必要度

`functional.xlsx` の「看護必要度」(`docs/functional-gap-backlog.md` §1 #7、§2.5)。**状態: 実装済(2026-10-10)。**
入力(患者 × 日の評価)と、病棟 × 月の該当患者割合の集計。

- **［事実］** = 通知・評価票、このリポジトリ・上流の実装で確認した内容
- **［設計］** = 本ドキュメントの決めごと
- **［要確認］** = 評価の手引き・疑義解釈で確かめていないこと

## 1. 評価票(令和8年度改定)

- **［事実］** 評価票は「一般病棟用の重症度、医療・看護必要度Ⅰに係る評価票」(基本診療料の施設基準等の通知 別紙7、
  令和8年度改定)を画像で確認して写した(2026-10-10)。
  - A モニタリング及び処置等: 1 創傷処置(褥瘡の処置を除く)1点 / 2 呼吸ケア(喀痰吸引のみの場合を除く)1点 /
    3 注射薬剤3種類以上の管理(最大7日間)1点 / 4 シリンジポンプの管理 1点 / 5 輸血や血液製剤の管理 2点 /
    6 専門的な治療・処置 ①抗悪性腫瘍剤の使用(注射剤のみ)3点 ②抗悪性腫瘍剤の内服の管理 2点 ③麻薬の使用(注射剤のみ)3点
    ④麻薬の内服、貼付、坐剤の管理 2点 ⑤放射線治療 2点 ⑥免疫抑制剤の管理(注射剤のみ)2点 ⑦昇圧剤の使用(注射剤のみ)3点
    ⑧抗不整脈剤の使用(注射剤のみ)3点 ⑨抗血栓塞栓薬の持続点滴の使用 3点 ⑩ドレナージの管理 2点 ⑪無菌治療室での治療 3点 /
    7 救急搬送後の入院(2日間)2点
  - B 患者の状況等(患者の状態 × 介助の実施): 8 寝返り(できる 0 / 何かにつかまればできる 1 / できない 2、介助なし)/
    9 移乗・11 食事摂取・12 衣服の着脱(自立 0 / 一部介助 1 / 全介助 2)/ 10 口腔清潔(自立 0 / 要介助 1)/
    13 診療・療養上の指示が通じる(はい 0 / いいえ 1、介助なし)/ 14 危険行動(ない 0 / ある 2、介助なし)
  - C 手術等の医学的状況(各 1 点): 15 開頭手術(11日間)/ 16 開胸手術(9日間)/ 17 開腹手術(6日間)/
    18 骨の手術(10日間)/ 19 胸腔鏡・腹腔鏡手術(4日間)/ 20 全身麻酔・脊椎麻酔の手術(5日間)/
    21 救命等に係る内科的治療(4日間)/ 22 別に定める検査(2日間)/ 23 別に定める手術(5日間)
  - 注: A3・A6①〜④・⑥〜⑨と C は、評価日に別表1 のレセプト電算処理システム用コードに該当するものの点数を記載する。
    急性期一般入院料1 等では B 得点を基準に用いないが毎日評価を行う。
- **［事実］** 該当患者の基準(解説記事で確認。告示の原文は未確認): 割合1 = A3点以上又はC1点以上、
  割合2 = A2点以上又はC1点以上。入院料により割合1だけ・両方を用いる。基準値(%)は入院料ごとに違う。
- **［要確認］** A6 に複数該当したときは小項目の最高点を数えている(合計にはしない)。評価の手引きで確かめる。
- **［要確認］** B の測定日の柔軟化(入院後 4 日間は毎日、その後は週 1 回で直近の評価で代えられる、とする解説がある)は
  持たない(毎日の評価を前提に、B は前日の評価を初期値にする)。

## 2. 持ち方

- **［設計］** 患者 × 日の `Observation` 1 件(`fhir/nursingAcuityHelpers.ts`):
  - `code` = `http://fhir-client.local/CodeSystem/nursing-acuity|general-2026`(評価票の版)、`category` = survey
  - `effectiveDateTime` = 評価日(日付のみ)、`subject` / `encounter` / `performer`(評価者)、`extension` = order-ward(評価した日の病棟)
  - `component`(system `.../nursing-acuity-item`): A・C の項目と A6 の小項目は `valueBoolean`、B の項目は状態の点数
    (`valueInteger`)、介助の実施は `<項目>-assist` の `valueBoolean`、合計 `A` `B` `C` の `valueInteger`
  - 対象外は `component` を持たず `dataAbsentReason`(not-applicable、text に理由)
  - 書き直しは同じ `Observation` を PUT(`status` = amended、版は transaction の If-Match)
- **［設計］** 評価票の項目・配点は版ごとに `NURSING_ACUITY_FORMS` に持つ。改定で変われば版を足し、施設設定で
  切り替える。過去の評価は `code` の版の定義で読む(合計も持つので、定義を知らない読み手も得点は読める)。
- **［設計］** 該当患者の基準は施設設定 `nursing_acuity`(`ratio1` / `ratio2` に組 `A3` `A2+B3` の並び。組の OR)。
  表示時の判定なので、変えれば過去の集計にも効く。

## 3. 評価の入力(`/nursing-acuity`「評価」)

- **［設計］** 行はその日に病棟のベッドに居た患者(`useWardInpatients`)。評価済みは得点・該当・評価者、未評価は強調。
- **［設計］** 新しく評価するときの初期値: B は前日の評価(患者の状況は日ごとに大きく変わらない)、A は実施記録から推す
  (`acuitySuggestions`。注射は MedicationAdministration の薬剤コードの種類数 ≥ 3 → A3、輸血 → A5、放射線治療の照射 → A6⑤、
  救急車搬送の入院の入院日と翌日 → A7)。実施記録は完了・実施中だけを数える。推した項目には根拠を出す。
- **［設計］** C は術式から区分(開頭・開胸…)を決められない(別表1 のコードが無い)ので、直近 11 日の手術を
  「術後何日」と並べ、看護師が選ぶ。
- **［設計］** 「前日複写」は前日の評価をまるごと写す(新規のときだけ)。
- **［設計］** 一括入力(`components/NursingAcuityBulkGrid.tsx`、評価タブの「一括入力」で切り替え): 行 = 患者、
  列 = 評価票の項目(`acuityColumns`。A6 は小項目ごとの列)。A・C と対象外はセルを押して切り替え、B はセレクト。
  介助の実施を掛ける B の項目は「状態・介助あり / なし」を 1 つのセレクトに並べる(`acuityStateOptions`。0 点の状態は
  介助を問わないので 1 つ)。初期値は 1 人ずつの評価と同じ(`initialAcuityValues`)で、実施記録は病棟の患者ぶんを
  40 人ずつまとめて引く(`useAcuityRecordsForPatients`)。
- **［設計］** 一括入力で登録するのは行の先頭のチェックを付けた患者だけ(セルを触った行には自動で付く)。未評価の患者の
  初期値(前日の B・記録から推した A)を確かめないまま評価として残さないため。登録は 1 つの transaction(上流のレート制限)。

## 4. 集計(`/nursing-acuity`「集計」)

- **［設計］** 病棟 × 月。日ごとに在棟(病棟のベッドを使っていた患者。入院日・退院日・移動日を含む。
  `wardPatientsByDay`)・評価・対象外・未評価(在棟 − 評価 − 対象外)・割合1/2 の該当数と割合(該当 ÷ 評価)。
  月の合計は延べ患者数で割る。今日より先の日は出さない。
- **［設計］** 評価は評価に焼き付けた病棟で数える(転棟した日は移動前後のどちらの病棟で評価したかで分かれる)。

## 5. 上流

- **［事実］** `Observation?code=<system>|<版>&patient=<複数>&date=ge..&date=le..` で引ける(患者は 40 人ずつ)。
  実施記録は `Procedure?patient&category=<注射・輸血・放射線治療・手術>&date=..&_revinclude=MedicationAdministration:part-of`。

## 6. 残っていること

- 必要度Ⅱ(別表1 のレセプト電算処理システム用コードを医事の実績・オーダーから当てる)。コード一覧のマスタ取込が前提
- A3 の除外薬剤(別表2)、A6 の対象薬剤(抗悪性腫瘍剤・麻薬・免疫抑制剤・昇圧剤・抗不整脈剤)の薬剤マスタでの判定。
  麻薬は `master_medicines.narcotic_category` があるので A6③④ から足せる
- 救急患者応需係数と割合指数(病床あたり救急搬送受入件数 × 0.005、上限あり)。救急搬送の件数は救急患者一覧から数えられる
- 入院料ごとの基準値(%)を持って下回る月を強調すること、届出の様式の出力
- ICU・HCU 用の評価票、B の測定日の柔軟化、評価者の研修修了の管理
