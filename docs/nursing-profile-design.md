# 看護プロファイル 設計

入院時に看護師が聴き取る、患者の生活と看護上の状態(入院の経緯、病気・入院の受け止め、ADL、睡眠・排泄、
コミュニケーション、転倒・褥瘡のリスクなど)。看護過程の情報収集(アセスメント)にあたり、看護計画
(`docs/nursing-care-plan-design.md`)の前段になる。本文中の区別は他の設計書と同じ(［事実］/［導出］/［提案］)。

---

## 1. 器: テンプレート(Questionnaire)に寄せる

［事実］入院時の看護情報の項目は施設ごとに大きく違う(ゴードンの機能的健康パターン、ヘンダーソンの基本的欲求、
施設独自の様式)。転倒・転落や褥瘡の評価票も施設が選ぶ。

［導出］専用の構造化フォームは作らず、テンプレート(`Questionnaire`)を施設が選んで並べる。設問の追加・変更は
テンプレート編集画面で行え、初期値の変数(`%allergies` など)、計算式、条件表示、Observation の生成といった
既存のテンプレートの機能がそのまま使える(基礎データ・社会歴と同じ考え方。readme「基礎データ」)。

- **区画 = テンプレート 1 本**。施設設定 `nursing_profile.templates` に、テンプレートの url を区画の順に並べる。
- 区画を分けるのは、評価し直す周期が違うものを別々に更新できるようにするため(転倒・褥瘡のリスクは入院時の
  聴き取りとは別に評価し直す)。1 枚の大きなテンプレートで運用したい施設は 1 つだけ並べればよい。
- 設定の値は **url(版なし)**。テンプレートの版を上げても施設設定を直さずに済む。新しく書く回答は有効な版の
  テンプレートを使い、書いた回答は書いた版のテンプレートで読む(`QuestionnaireResponse.questionnaire` は
  版込みの canonical のまま)。

## 2. FHIR の持ち方

- **1 入院 × 1 区画 = 1 件の `QuestionnaireResponse`**。`encounter` に入院を持つ(`buildQuestionnaireResponse` の
  `encounterId`。更新では保存済みの値を引き継ぐ)。
- 書き直しは同じ回答の更新(PUT、`If-Match`)。版の履歴は上流の `_history` に残る。看護プロファイルは
  「入院中に書き直していく今の状態」で、時系列に積み上げる記録ではないため。
- **読み込み**: `QuestionnaireResponse?encounter=Encounter/{id}&questionnaire:not={DPC 様式1}&_include=QuestionnaireResponse:questionnaire`。
  上流の `questionnaire` 検索は版込みの完全一致なので区画の url では引けない。入院に結び付く回答は DPC 様式1 と
  看護プロファイルだけなので、入院で引いて様式1 を除き、url ごとに振り分ける(`nursingProfileSections`)。
  1 区画に複数あれば記入日時の新しいものを採る。
- **カルテの時系列には出さない**。時系列の検索は `encounter:missing=true` で、入院に結び付いた回答
  (DPC 様式1・看護プロファイル)をまとめて除く。

## 3. 画面

### 3.1 右ペインのボタン

［事実］右ペインの登録ボタンの列は、いちばん長いラベル(「クリニカルパス」「退院時サマリー」の 7 文字)で幅が決まる。
看護のボタンは見出し「看護」の下に畳んである(`PaneActionGroup`)。

［導出］ボタンは「看護」の下に置き、名前は **「プロファイル」**(6 文字)にする。「看護プロファイル」(8 文字)にすると
列が広がる。見出しが「看護」なので患者プロファイル(タブ「患者情報」>「プロファイル」)と取り違えにくい。
並びは看護過程の順(プロファイル → 看護計画 → 看護診断 → 看護指示 → 看護サマリー)。

### 3.2 右ペイン(`NursingProfilePanel`)

- 対象の入院(既定は今の入院、無ければ最新の退院)と区画のボタン列。記入済みの区画には「済」を付ける。
- その入院・区画の回答があれば編集(`QuestionnaireResponseEditPanel`)、無ければ新規(`QuestionnaireResponseCreatePanel` に
  区画のテンプレートを固定で渡す)。どちらもテンプレート回答の汎用パネルで、対象プロブレムの欄は出さない。
- **前回入院からの複写**は、テンプレート回答の「前回値複写」(同じテンプレート・同じ版の直近の回答)をそのまま使う。
  その入院に回答があれば編集に切り替わるので、新規で出る「前回」は必ず前の入院の回答になる。版をまたいで複写しない
  のもテンプレート回答と同じ(設問が変わっていれば回答の対応が崩れる)。

### 3.3 タブ(`KarteNursingProfileTab`)

- タブ群「看護」の先頭に「看護プロファイル」。入院を選び(`view` に入院の id)、区画ごとに状態・記入日時・記入者と
  回答の平文を並べる。
- 区画の「記入」「編集」は右ペインで開く(右ペインの登録ボタンから始める登録の編集なので、右ペインを使う)。

## 4. 同梱の雛形

`docs/report-mappings/nursing-profile.md` を参照。入院時情報・生活・ADL・転倒・転落リスク・褥瘡リスクの 4 区画。

## 5. 申し送り

- 外来の患者(入院が無い)には書けない。外来看護で使う要件が出たら、入院に結び付かない 1 件を患者ごとに持つ形を足す。
- 看護サマリーの下書きの候補に看護プロファイルの要約を足す案は未実装。
- 初期値の変数にキーパーソン(`Patient.contact`)・使用言語・社会歴は無い。雛形では手入力にしている。
- 初期値の入院の変数(`%admissionDate` など)は今の入院を指す。退院済みの入院に書くときはずれる。
- 区画の設定から外したテンプレートの回答は、タブにも右ペインにも出なくなる(上流には残る)。
